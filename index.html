Como publicarlo gratis en Netlify

  1. Sube esta carpeta completa a un repositorio de GitHub o arrastrala directo a Netlify Drop.
  2. El archivo index.html de la raiz sera la portada publica del sitio.
  3. Comparte la URL *.netlify.app y mas adelante, si quieres, conectas tu dominio propio sin rehacer el contenido.

Los cursos principales ya estan preparados como sitio estatico puro, asi que no necesitas build, Node, base de datos ni plan de pago para ponerlos en linea.
