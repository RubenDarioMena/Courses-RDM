Módulo 03: Creando tus Propias Herramientas 🛠️

¡Bienvenido al Módulo 3! Ya sabes guardar datos y hacer que tu código tome decisiones. Ahora, subiremos de nivel. Vamos a aprender a crear nuestros propios "mini-programas" dentro del programa principal. Se llaman funciones, y son, sin duda, la herramienta más poderosa que tendrás como programador. Son como crear tus propios hechizos personalizados: los defines una vez y los usas mil veces. ¡Vamos a ello!

Lección 1: Las Mil y Una Formas de Crear una Función 📜

Una función es un bloque de código reutilizable que realiza una tarea específica. Imagina que es una receta de cocina: la escribes una vez ("Receta para hacer un pastel") y puedes seguirla siempre que quieras un pastel, sin tener que reinventar los pasos cada vez. En JavaScript, hay dos formas principales de escribir estas "recetas".

1. Declaración de Función: El método clásico

Esta es la forma más tradicional. Es como presentar a un personaje al principio de una película. Le dices a JavaScript: "Oye, va a existir una función llamada 'saludar'".

// Declaramos la función 'saludar'
function saludar(nombre) {
alert(¡Hola, ${nombre}! Un gusto conocerte.);
}

// Ahora podemos usarla (llamarla) cuantas veces queramos
saludar('Ana');
saludar('Carlos');

2. Expresión de Función: El método moderno

Aquí, creamos una función y la guardamos dentro de una variable, como si fuera un número o un texto. Es como si un personaje apareciera de repente en la trama y dijera: "Por cierto, soy el mago y me llamo 'despedir'".

// Creamos una función anónima y la asignamos a la variable 'despedir'
const despedir = function(nombre) {
alert(¡Hasta luego, ${nombre}!);
};

// La usamos a través de la variable
despedir('Ana');

La Diferencia Clave: Hoisting (Elevación) 🚀

Imagina que el motor de JavaScript lee tu código en dos pasadas. En la primera, busca todas las Declaraciones de Función (las del método clásico) y las "eleva" al principio de todo. Por eso, puedes llamar a una función declarada ¡incluso ANTES de haberla escrito en el código!

Las Expresiones de Función no se elevan. Viven donde las escribes. Si intentas llamarla antes, JavaScript te dará un error porque la "caja" (la variable) existe, pero la "receta" (la función) aún no está dentro.

Regla simple: Para empezar, no te compliques. Pero es vital saber que esta diferencia existe.

// ¡La magia del Hoisting en acción!
diHola(); // Funciona perfectamente, aunque la función está definida más abajo.

function diHola() {
alert('¡Hola!');
}

// ¡Aquí no hay magia!
// diAdios(); // Si descomentas esta línea, tendrás un ReferenceError.

const diAdios = function() {
alert('¡Adiós!');
};

3. Funciones Flecha: La versión corta y cool 😎

Las funciones flecha son una forma más moderna y compacta de escribir Expresiones de Función. ¡Son geniales!

// Expresión de Función clásica
const sumarClasico = function(a, b) {
return a + b;
};

// ¡La misma función, pero en modo flecha!
const sumarFlecha = (a, b) => a + b;

// Si solo tiene una línea, ¡las llaves {} y el 'return' son implícitos!
alert(sumarFlecha(5, 3)); // Muestra 8

// Si solo tienes un parámetro, los paréntesis son opcionales
const cuadrado = numero => numero * numero;

// Si no tienes parámetros, necesitas paréntesis vacíos
const saludoRandom = () => alert('¡Hey!');
Lección 2: Pasando Ingredientes a tus Funciones 🥕

Una receta no es muy útil si siempre usa los mismos ingredientes. ¡Queremos poder decirle: "hoy haz el pastel con chocolate" y mañana "hazlo con vainilla"! Para eso sirven los parámetros y argumentos.

Parámetros vs. Argumentos: La Lista y la Compra

Parámetro: Es el nombre del ingrediente que pones en la lista de tu receta. Es una variable local de la función. "Necesitaré algo llamado sabor y algo llamado cobertura".

Argumento: Es el ingrediente real que le das a la receta cuando la preparas. "Ok, para sabor te doy 'chocolate' y para cobertura te doy 'chispas'". 

// 'sabor' y 'cobertura' son los PARÁMETROS
function hornearPastel(sabor, cobertura) {
console.log(Horneando un delicioso pastel de ${sabor} con cobertura de ${cobertura}.);
}

// 'chocolate' y 'chispas' son los ARGUMENTOS
hornearPastel('chocolate', 'chispas');

Valores por Defecto: El "por si acaso"

¿Qué pasa si te olvidas de pasar un ingrediente? Por defecto, JavaScript lo considera undefined. Para evitar problemas, podemos especificar un ingrediente "por si acaso" directamente en la lista.

function pedirCafe(tipo, azucar = 'normal') {
alert(Un café ${tipo} con azúcar ${azucar}, por favor.);
}

pedirCafe('espresso'); // Muestra "Un café espresso con azúcar normal, por favor."
pedirCafe('latte', 'morena'); // Muestra "Un café latte con azúcar morena, por favor."

Parámetros Rest (...): La bolsa de ingredientes sin fondo

A veces no sabes cuántos ingredientes te van a dar. ¿Uno? ¿Cinco? ¿Mil? Los parámetros "Rest" (que se escriben con tres puntos ...) agrupan todos los argumentos extra en un verdadero array. ¡Son súper útiles!

Pro Tip: Antes existía algo llamado arguments, que era un "objeto parecido a un array" pero no un array de verdad. Era más torpe y no tenía los métodos útiles como .map() o .filter(). Hoy en día, siempre deberías preferir los parámetros Rest (...). Es más limpio y poderoso.

// 'chef' es el primer parámetro, '...ingredientes' es el RESTO en un array
function crearEnsalada(chef, ...ingredientes) {
alert(El chef ${chef} va a usar:);
// Como 'ingredientes' es un array, podemos usar un forEach!
ingredientes.forEach(ingrediente => {
alert(- ${ingrediente});
});

crearEnsalada('Ana', 'lechuga', 'tomate', 'pepino', 'zanahoria');
Lección 3: Lo que la Función se Llevó (y te Devolvió) 📤

Las funciones no solo hacen cosas, ¡también pueden devolverte un resultado! Piensa en una calculadora: le das números (argumentos) y te devuelve (retorna) una respuesta. Para esto, usamos la palabra clave return.

La magia del return

Cuando JavaScript ve un return dentro de una función, hace dos cosas:

  • Detiene la ejecución de la función inmediatamente. Cualquier código que haya después del return es ignorado.
  • Devuelve el valor que le indiques al lugar desde donde se llamó la función.
function calcularAreaCirculo(radio) {
if (radio < 0) {
return 'Error: el radio no puede ser negativo.'; // Detiene la función aquí
}
const area = 3.14159 * (radio ** 2);
return area; // Devuelve el resultado del cálculo
console.log('Este mensaje nunca se mostrará');
}

let resultado = calcularAreaCirculo(10);
alert(El área es: ${resultado}); // El valor de 'area' se guardó en 'resultado'

let resultadoMalo = calcularAreaCirculo(-5);
alert(resultadoMalo); // Muestra el mensaje de error

¿Y si no hay return?

Una función que no devuelve nada explícitamente, o que tiene un return; vacío, devuelve undefined por defecto. Es como preguntarle algo a alguien y que se encoja de hombros.

Lección 4: Scope, o "¿Dónde Diablos Viven mis Variables?" 🏡

El Scope (o ámbito) es el conjunto de reglas que determinan desde dónde puedes ver o acceder a una variable. Es como la visibilidad en una casa: hay cosas en el salón (globales) que todos ven, y cosas en tu habitación (locales) que solo tú puedes ver.

Variables Locales vs. Globales

Variables Locales: Viven y mueren dentro de una función. Nadie fuera de la función sabe que existen. Son los secretos de la función.

Variables Globales: Se declaran fuera de cualquier función. Son como el WiFi de la casa: accesibles desde cualquier habitación (función). 

const wifiPassword = 'SuperSecret123'; // Variable Global

function conectarDispositivo() {
const nombreDispositivo = 'Mi Laptop'; // Variable Local
console.log(Conectando ${nombreDispositivo} usando la clave: ${wifiPassword}); // Puede ver ambas!
}

conectarDispositivo();

// console.log(nombreDispositivo); // ¡ERROR! No puedes ver una variable local desde fuera.
console.log(La clave global es: ${wifiPassword}); // Esto sí funciona.

Ejercicio 1: La Función Detective 🔍

Crea una función llamada investigarCaso que tome 3 parámetros: sospechoso, arma y lugar. La función debe usar una plantilla literal para devolver un mensaje como: "El detective encontró a Juan con un cuchillo en la cocina". Prueba la función con diferentes valores.

Pista:

function investigarCaso(sospechoso, arma, lugar) {
    return `El detective encontró a ${sospechoso} con ${arma} en ${lugar}`;
}

// Prueba tu función:
alert(investigarCaso('Ana', 'un libro', 'la biblioteca'));

Ejercicio 2: Calculadora Personalizada 🧮

Crea una función flecha llamada calcular que tome 3 parámetros: num1, num2 y operacion. Dependiendo del valor de operacion ('suma', 'resta', 'multiplicacion', 'division'), debe realizar la operación correspondiente y devolver el resultado. ¡Incluye validación para la división por cero!

Pista:

const calcular = (num1, num2, operacion) => {
    if (operacion === 'suma') {
        return num1 + num2;
    } else if (operacion === 'resta') {
        return num1 - num2;
    } // ... completar las demás operaciones
};

// Prueba tu función:
alert(calcular(10, 5, 'suma')); // Debería mostrar 15

Ejercicio 3: El Chef Maestro 👨‍🍳

Crea una función llamada prepararReceta que tome el nombre del chef como primer parámetro, y luego use parámetros rest (...) para recibir una lista de ingredientes. La función debe devolver un mensaje que liste todos los ingredientes que el chef va a usar. ¡Usa un bucle para mostrar la lista!

Pista:

function prepararReceta(chef, ...ingredientes) {
    let mensaje = `El chef ${chef} va a cocinar con:\n`;
    ingredientes.forEach(ingrediente => {
        mensaje += `- ${ingrediente}\n`;
    });
    return mensaje;
}

// Prueba tu función:
alert(prepararReceta('Gordon Ramsay', 'carne', 'papas', 'especias secretas'));

Ejercicio 4: Analizador de Texto 📝

Crea una función flecha llamada analizarTexto que tome un texto y devuelva un objeto con información: la longitud del texto, la cantidad de palabras, y si contiene la palabra "JavaScript". ¡Demuestra que entiendes el scope usando variables locales!

Pista:

const analizarTexto = (texto) => {
    const longitud = texto.length;
    const palabras = texto.split(' ').length;
    const tieneJS = texto.includes('JavaScript');
    
    return {
        longitud: longitud,
        palabras: palabras,
        tieneJavaScript: tieneJS
    };
};

// Prueba tu función:
const resultado = analizarTexto('Me encanta JavaScript');
alert(`Longitud: ${resultado.longitud}, Palabras: ${resultado.palabras}, ¿Tiene JS? ${resultado.tieneJavaScript}`);
