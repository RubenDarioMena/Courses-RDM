Módulo 03: Lógica y Control de Flujo 🚦

¡Has llegado al Módulo 03! Aprenderás a controlar el flujo de tu programa, es decir, a decidir qué camino tomar y cuándo repetir una acción con condicionales y bucles.

La Base de las Decisiones: Booleanos

Para tomar una decisión, un programa evalúa si una afirmación es verdadera (True) o falsa (False).

Operadores de Comparación

edad = 20
puntuacion = 95
print("¿La edad es igual a 20?", edad == 20) # True
print("¿La puntuación es diferente de 100?", puntuacion != 100) # True
print("¿Es mayor de edad?", edad >= 18) # True

Operadores Lógicos: `and`, `or`, `not`

edad = 25
tiene_licencia = True
# 'and' requiere que AMBAS condiciones sean verdaderas
puede_conducir = edad >= 18 and tiene_licencia
print("¿Puede conducir legalmente?", puede_conducir) # True
# 'not' invierte el resultado booleano
es_menor = not (edad >= 18)
print("¿Es menor de edad?", es_menor) # False

Tomando Caminos: if, elif y else

Son las señales de tráfico de tu programa. Le dicen qué bloque de código ejecutar.

`if` y `else`

edad = 16
if edad >= 18:
    print("Puedes pasar a la zona de adultos.")
else:
    print("Lo siento, esta zona es solo para mayores de 18.")

Múltiples Condiciones con `elif`

nota = 75
if nota >= 90:
    calificacion = "A"
elif nota >= 80:
    calificacion = "B"
elif nota >= 70:
    calificacion = "C"
else:
    calificacion = "D"
print(f"Tu calificación es: {calificacion}") # Muestra "C"

Repitiendo Tareas con `while`

El bucle while repetirá el código que contiene mientras su condición sea True.

# Vamos a contar del 1 al 5
contador = 1  # 1. Inicializamos la variable
while contador <= 5:  # 2. Definimos la condición
    print(f"El contador es: {contador}")
    contador = contador + 1  # 3. ¡Crucial! Modificamos la variable
print("¡Bucle terminado!")

Saliendo de un Bucle con `break`

numero_magico = 7
intento = 1
while True:  # Este bucle sería infinito por sí solo
    print(f"Intento número {intento}...")
    if intento == numero_magico:
        print("¡Lo encontré! Era el 7.")
        break  # Salimos del bucle
    intento += 1  # Forma corta de escribir intento = intento + 1

Repitiendo de Forma Elegante con `for`

Su superpoder es recorrer cualquier "secuencia" de elementos de principio a fin.

La Función `range()`

# Cuenta regresiva desde 5 hasta 1
print("Lanzamiento en:")
for i in range(5, 0, -1):
    print(i)
print("¡Despegue!")

# Imprimir los números pares del 2 al 10
print("\nNúmeros pares:")
for num in range(2, 11, 2):
    print(num)

Saltando una Iteración con `continue`

# Imprimir todos los números del 1 al 10, excepto el 5 y el 7.
for numero in range(1, 11):
    if numero == 5 or numero == 7:
        continue  # Si es 5 o 7, no hagas el print y pasa al siguiente
    print(f"Procesando número: {numero}")
