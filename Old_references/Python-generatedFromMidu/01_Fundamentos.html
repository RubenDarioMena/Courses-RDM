Módulo 01: Fundamentos de Python 🚀

¡Felicidades por empezar! En el módulo anterior, preparamos nuestro entorno. Ahora, es el momento de la verdad: vamos a escribir nuestras primeras líneas de código para comunicarnos con la computadora.

Tu Primera Conversación con print()

La función print() es la herramienta más fundamental de Python. Es como la "voz" de tu programa. La usarás constantemente para mostrar mensajes, ver los resultados de tus operaciones y entender qué está pasando dentro de tu código.

Imprimiendo un Mensaje Simple

# Esta es tu primera línea de código funcional. ¡Ejecútala!
print("¡Hola, mundo!")

# También puedes usar comillas simples.
print('Python es increíble.')

Mostrando Múltiples Elementos

print("Mi edad es", 30, "años.")

Controlando la Salida con `sep` y `end`

# Usando 'sep' para unir con guiones
print("Python", "es", "genial", sep="-")

# Usando 'end' para evitar el salto de línea y continuar en la misma línea
print("Esto se imprime en la misma línea", end=" ")
print("que esto.")

F-Strings: Cadenas de Texto Formateadas

Los f-strings (cadenas de texto formateadas) son una forma moderna y legible de crear cadenas de texto dinámicas. Te permiten insertar variables directamente dentro de un string de manera muy sencilla, prefijando la cadena con la letra f.

# Creamos algunas variables para usar en el f-string
nombre = "Ana"
puntos = 150

# Usamos un f-string para combinar texto y variables
print(f"¡Hola, {nombre}! Has obtenido {puntos} puntos.")

Comentarios: Escribiendo Notas para ti y otros Desarrolladores

Los comentarios son líneas de texto que el intérprete de Python ignora por completo. Son esenciales para explicar tu código, hacerlo más legible y recordar la lógica detrás de tus decisiones de programación. No tienes que comentar cada linea de código, solo partes importantes o que se presten a ambiguedades. Con el tiempo y la práctica desarrollaras mejor el criterio necesario para saber cuándo es necesario comentar algo.

Comentario de una sola línea

Usa el signo de almohadilla (#) para crear un comentario de una sola línea. Todo lo que esté después del # en esa línea no será ejecutado.

# Este es un comentario que explica la siguiente línea de código
print("Hello, Python!") 
# La línea de arriba imprime un saludo
Comentario de múltiples líneas

En Python, no hay una sintaxis oficial para comentarios de varias líneas como en otros lenguajes. La convención es usar tres comillas dobles (""") o simples ('''). Esto crea un docstring, que es una cadena de texto que no se asigna a ninguna variable y se utiliza comúnmente para documentar funciones y módulos, pero también puede servir como un comentario multilinea.

"""
Este es un comentario de múltiples líneas.
Puede extenderse a través de varias líneas
para explicar bloques de código más grandes.
"""
print("Estoy usando un comentario multilinea.")
Limpiar la consola

Si en lugar de usar el interprete embebido en las lecciones decides usar uno propio y tienes que imprimir mucho codigo (como cualquiera que esta aprendiendo un lenguaje nuevo). El siguiente codigo te ayudará a limpiar automaticamente la consola cada que ejecutes el codigo. Además sirve como pequeña introduccion a importar modulos a python, algo fundamental para añadir más funciones al lenguaje. 

# Podemos importar módulos de Python para usarlos en nuestros programas.
# En este caso, importamos el módulo "os" que nos da acceso a funciones
# relacionadas con el sistema operativo
from os import system

# system() nos permite ejecutar un comando en la terminal.
# En este caso, lo hacemos para limpiar la pantalla tanto
# en MacOS/Linux usando "clear" como en Windows con "cls"
if system("clear") != 0: system("cls")

Guardando Información: Variables

Una variable es como una caja con una etiqueta. Puedes guardar algo dentro y usar la etiqueta para referirte a ello más tarde.

# Creamos una variable y le asignamos un valor
nombre_heroe = "Spider-Man"
edad = 25

# Ahora podemos usar la variable en lugar del valor directo
print("Mi héroe favorito es", nombre_heroe)
print(nombre_heroe, "tiene", edad, "años.")

Tipos de Datos Fundamentales

  • int: Números enteros (ej: 10, -5).
  • float: Números con decimales (ej: 3.14).
  • str: Cadenas de texto (ej: "Hola").
  • bool: Valores de verdad: True o False.
# Python deduce el tipo de dato automáticamente
numero_entero = 42
numero_decimal = 9.99
texto = "Este es un string"
es_verdadero = True

# Podemos usar la función type() para comprobarlo
print(type(numero_entero)) # Muestra <class 'int'>
print(type(es_verdadero)) # Muestra <class 'bool'>

Interactuando con los Datos

Operadores Aritméticos

resultado_suma = 10 + 5  # 15
resultado_division = 20 / 4  # 5.0 (la división normal siempre da un float)
resultado_potencia = 2 ** 3  # 8 (2 elevado a 3)
print("El resultado de la suma es:", resultado_suma)

# El operador + también concatena (une) strings
saludo = "Hola" + " " + "mundo"
print(saludo) # Muestra "Hola mundo"

Operadores de Asignación Compuesta

Estos operadores combinan una operación aritmética con la asignación (=). Son una forma abreviada de escribir código y muy comunes. Aquí están los más útiles:

  • += x += 5 es lo mismo que x = x + 5.
  • -= x -= 3 es lo mismo que x = x - 3.
  • *= x *= 2 es lo mismo que x = x * 2.
  • /= x /= 4 es lo mismo que x = x / 4.
saldo = 100

# Aumenta el saldo en 50, usando el operador de asignación +=
saldo += 50
print("Saldo después de un depósito:", saldo) # Muestra 150

# Reduce el saldo a la mitad, usando el operador de asignación /=
saldo /= 2
print("Saldo después de un gasto:", saldo) # Muestra 75.0

Pidiendo Información al Usuario con `input()`

Importancia: input() es el puente de interacción entre tu programa y quien lo usa (e incluso con el entorno cuando se leen datos de sensores). Lo usarás con frecuencia para que el programa reciba información.

  • ¿Qué hace? Muestra un mensaje (el “prompt”).
  • Pausa el programa hasta que la persona escribe y presiona Enter.
  • Devuelve SIEMPRE un str (texto), aunque parezca número.
  • Si quieres hacer matemáticas, primero convierte ese texto a número con int() o float() (lo veremos más adelante).
nombre_usuario = input("Por favor, introduce tu nombre: ")
print(f"¡Hola, {nombre_usuario}! Encantado de conocerte.")

edad_texto = input("¿Cuántos años tienes? ")
print("El tipo de dato de la edad introducida es:", type(edad_texto))

Transformando Datos

El casting es el proceso de convertir un valor de un tipo de dato a otro. Usamos int(), float(), str().

edad_texto = input("Introduce tu edad de nuevo: ")
# Hacemos el casting para convertir el string a un número entero
edad_numero = int(edad_texto)

# ¡Ahora sí podemos hacer operaciones matemáticas!
print(f"El año que viene tendrás {edad_numero + 1} años.")

# De número a string
puntos = 100
                        mensaje = "Has ganado " + str(puntos) + " puntos."
                        print(mensaje)

Optimizando el Código: Combinando `input` y `int`

A menudo, verás que la captura de un número y su conversión se hacen en una sola línea. Es una forma más compacta y eficiente de escribir el mismo código.

# La versión corta y directa
edad = int(input("Introduce tu edad de nuevo: "))
print(f"En 5 años tendrás {edad + 5} años.")
¿Cuándo usar cada forma?
  • Forma Larga (separada): Es ideal cuando estás aprendiendo. Te permite ver cada paso claramente: primero capturas el texto, luego lo conviertes. También es útil si necesitas la versión en texto del input para otra cosa antes de convertirla.
  • Forma Corta (combinada): Es la más común en el código de producción. Úsala cuando estés seguro de que el único propósito de ese `input` es obtener un número para hacer cálculos. Es más concisa y se considera más "pythonic" (idiomática de Python). Sin embargo, si el usuario introduce algo que no es un número (como "veinte"), el programa se detendrá con un error. Más adelante aprenderemos a manejar estos errores.

Esta clase de "trucos" serán comunes a lo largo del curso, y por ello es importante contar con un compilador a la mano, para permitirte probar y romper el código, así explorando todas estas posibilidades que permite Python.

f-strings: expresivos y precisos

En un f-string puedes poner expresiones entre llaves {}: operaciones, llamadas a funciones y condicionales. Tras : agrega especificadores de formato como .2f, ,, >10, etc.

Ejemplos rápidos

a, b = 10, 3
print(f"{a + b}")   # 13 (aritmética)
print(f"{(a/b):.2f}")   # 3.33 (decimales)
print(f"{a:,}") # 10 (separador miles)
nombre = "Ada"
print(f"{nombre.upper()}")                # ADA (método)
print(f"{a if a>b else b}")   # 10 (condicional)
print(f"{a=}")                          # a=10 (debug)

Ejercicio resuelto: ticket de compra

Integra input(), variables, operadores, casting y f-strings para calcular un total con impuestos.

producto = input("Nombre del producto: ")
precio_txt = input("Precio unitario: ")
cantidad_txt = input("Cantidad: ")

# Casting
precio = float(precio_txt)
cantidad = int(cantidad_txt)

# Operaciones
subtotal = precio * cantidad
iva = subtotal * 0.16
total = subtotal + iva

# Salida con f-strings y formato
print(f"Producto: {producto}")
print(f"Subtotal: $ {(subtotal):,.2f}")
print(f"IVA (16%): $ {(iva):,.2f}")
print(f"Total: $ {(total):,.2f}")

Tip: usa , para miles y .2f para dos decimales dentro del formato.
