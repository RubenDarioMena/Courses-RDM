Sección 1: Fundamentos de Robótica con Python

1.1: Control de Hardware con GPIO (LEDs)

Usaremos una Raspberry Pi y su interfaz GPIO (General Purpose Input/Output) para controlar un LED. Necesitarás la librería RPi.GPIO.

# pip install RPi.GPIO
import RPi.GPIO as GPIO
import time

LED_PIN = 17 # Pin GPIO 17

# Configurar el modo de los pines (BCM se refiere a los números de GPIO)
GPIO.setmode(GPIO.BCM)
# Configurar el pin del LED como salida
GPIO.setup(LED_PIN, GPIO.OUT)

try:
    print("Haciendo parpadear el LED. Presiona CTRL+C para salir.")
    while True:
        GPIO.output(LED_PIN, GPIO.HIGH) # Encender LED
        time.sleep(1) # Esperar 1 segundo
        GPIO.output(LED_PIN, GPIO.LOW)  # Apagar LED
        time.sleep(1)
except KeyboardInterrupt:
    print("\nLimpiando los pines GPIO...")
finally:
    GPIO.cleanup() # Restablece los pines a su estado inicial
1.2: Lectura de Sensores (Pulsador)

Leeremos la entrada de un sensor digital, como un botón. Esto nos permite que el robot reaccione a su entorno.

import RPi.GPIO as GPIO
import time

BUTTON_PIN = 18
LED_PIN = 17

GPIO.setmode(GPIO.BCM)
GPIO.setup(LED_PIN, GPIO.OUT)
# Configurar el pin del botón como entrada con resistencia pull-down
GPIO.setup(BUTTON_PIN, GPIO.IN, pull_up_down=GPIO.PUD_DOWN)

print("Presiona el botón para encender el LED. CTRL+C para salir.")

try:
    while True:
        if GPIO.input(BUTTON_PIN) == GPIO.HIGH:
            GPIO.output(LED_PIN, GPIO.HIGH)
        else:
            GPIO.output(LED_PIN, GPIO.LOW)
        time.sleep(0.1) # Pequeña pausa para evitar uso excesivo de CPU
except KeyboardInterrupt:
    print("\nLimpiando...")
finally:
    GPIO.cleanup()
1.3: Control de Actuadores con PWM (Servomotor)

Los servomotores permiten un control preciso del ángulo. Usaremos PWM (Pulse Width Modulation) para mover un servo a posiciones específicas.

import RPi.GPIO as GPIO
import time

SERVO_PIN = 25
GPIO.setmode(GPIO.BCM)
GPIO.setup(SERVO_PIN, GPIO.OUT)

# Crear un objeto PWM con frecuencia de 50Hz
pwm = GPIO.PWM(SERVO_PIN, 50)
pwm.start(0) # Iniciar PWM con ciclo de trabajo 0

def set_angle(angle):
    # El ciclo de trabajo va de 2 a 12 para ángulos de 0 a 180
    duty = angle / 18 + 2
    GPIO.output(SERVO_PIN, True)
    pwm.ChangeDutyCycle(duty)
    time.sleep(1) # Dar tiempo al servo para moverse
    GPIO.output(SERVO_PIN, False)
    pwm.ChangeDutyCycle(0)

try:
    print("Moviendo el servo...")
    set_angle(0)
    set_angle(90)
    set_angle(180)
    set_angle(90)
except KeyboardInterrupt:
    print("\nDeteniendo servo...")
finally:
    pwm.stop()
    GPIO.cleanup()

NumPy es esencial para la IA. Las imágenes, por ejemplo, se representan como arrays de NumPy.

# pip install numpy
import numpy as np

# Crear un array 1D
a = np.array([1, 2, 3])

# Crear un array 3D (como una imagen a color RGB)
# 2x2 píxeles, 3 canales de color (R, G, B)

img[0, 0] = [255, 0, 0] # Píxel rojo
img[0, 1] = [0, 255, 0] # Píxel verde
print(f"\nArray 3D (imagen):\n{img}")
2.2: OpenCV para Visión por Computadora

OpenCV es la librería estándar para procesar imágenes y video.

# pip install opencv-python
import cv2

# Capturar video desde la webcam
cap = cv2.VideoCapture(0)

if not cap.isOpened():
    print("Error: No se puede abrir la cámara")
    exit()

while True:
    # Leer un frame
    ret, frame = cap.read()
    if not ret:
        break

    # Convertir a escala de grises
    gray_frame = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)

    # Mostrar el frame original y el procesado
    cv2.imshow('Original', frame)
    cv2.imshow('Escala de Grises', gray_frame)

    # Salir con la tecla 'q'
    if cv2.waitKey(1) == ord('q'):
        break

# Liberar recursos
cap.release()
cv2.destroyAllWindows()
2.3: Inferencia con Modelos de Visión (Local)

Usaremos un modelo pre-entrenado con OpenCV para detectar objetos comunes en tiempo real.

# Descargar 'MobileNetSSD_deploy.prototxt.txt' y 'MobileNetSSD_deploy.caffemodel'
import cv2
import numpy as np

# Cargar el modelo
net = cv2.dnn.readNetFromCaffe('MobileNetSSD_deploy.prototxt.txt', 'MobileNetSSD_deploy.caffemodel')
CLASSES = ["background", "aeroplane", "bicycle", "bird", "boat",
	"bottle", "bus", "car", "cat", "chair", "cow", "diningtable",
	"dog", "horse", "motorbike", "person", "pottedplant", "sheep",
	"sofa", "train", "tvmonitor"]

cap = cv2.VideoCapture(0)

while True:
    ret, frame = cap.read()
    if not ret: break

    (h, w) = frame.shape[:2]
    blob = cv2.dnn.blobFromImage(cv2.resize(frame, (300, 300)), 0.007843, (300, 300), 127.5)

    net.setInput(blob)
    detections = net.forward()

    for i in np.arange(0, detections.shape[2]):
        confidence = detections[0, 0, i, 2]
        if confidence > 0.5: # Umbral de confianza
            idx = int(detections[0, 0, i, 1])
            box = detections[0, 0, i, 3:7] * np.array([w, h, w, h])
            (startX, startY, endX, endY) = box.astype("int")
            label = f"{CLASSES[idx]}: {confidence:.2f}%"
            cv2.rectangle(frame, (startX, startY), (endX, endY), (0, 255, 0), 2)
            cv2.putText(frame, label, (startX, startY - 15), cv2.FONT_HERSHEY_SIMPLEX, 0.5, (0, 255, 0), 2)

    cv2.imshow("Detector de Objetos", frame)
    if cv2.waitKey(1) == ord('q'): break

cap.release()
cv2.destroyAllWindows()

Sección 5: Proyectos Finales Sugeridos

Proyecto 1: Robot de Vigilancia Autónomo

Objetivo: Construir un vehículo robótico que pueda navegar de forma autónoma por una habitación, detectar la presencia de personas y enviar una alerta.

Componentes: Chasis de robot con motores, controlador de motores (L298N), Raspberry Pi, cámara, batería.

Pasos:

  1. Monta el chasis del robot y conecta los motores al controlador y a la Raspberry Pi.
  2. Programa las funciones básicas de movimiento: avanzar, retroceder, girar.
  3. Integra la cámara y el modelo de detección de personas.
  4. Crea la lógica: el robot avanza hasta que un sensor de distancia detecta un obstáculo. Gira y continúa.
  5. Si detecta una persona, el robot se detiene, captura una imagen y la envía por email o a un bot de Telegram.
Proyecto 2: Asistente de Jardinería Inteligente

Objetivo: Crear un sistema automatizado que cuide de una planta, monitorizando la humedad de la tierra y regándola cuando sea necesario.

Componentes: Sensor de humedad del suelo, Raspberry Pi, relé, pequeña bomba de agua, mangueras.

Pasos:

  1. Conecta el sensor de humedad a un pin de entrada analógica (puede requerir un conversor ADC como el MCP3008).
  2. Conecta la bomba de agua a la Raspberry Pi a través de un relé (el relé actúa como un interruptor seguro para manejar el voltaje de la bomba).
  3. Escribe un script que lea el valor del sensor cada hora.
  4. Define un umbral de humedad. Si el valor leído está por debajo del umbral, activa el relé durante unos segundos para regar la planta.
  5. (Opcional) Crea una pequeña web con Flask para mostrar el nivel de humedad actual y un botón para regar manualmente.
Proyecto 3: Intérprete de Lenguaje de Señas

Objetivo: Desarrollar una aplicación que utilice la visión por computadora para reconocer gestos básicos del lenguaje de señas y los traduzca a texto.

Componentes: Cámara web, un ordenador con buen rendimiento.

Pasos:

  1. Investiga sobre datasets de imágenes de lenguaje de señas (ej. ASL Alphabet).
  2. Usa una librería como `TensorFlow` o `PyTorch` para entrenar tu propio modelo de clasificación de imágenes. El modelo aprenderá a asociar una imagen de una mano con una letra.
  3. Usa `OpenCV` para capturar video de la cámara. Aísla la región de la mano en el video.
  4. Pasa la imagen de la mano a tu modelo entrenado para que prediga la letra correspondiente en tiempo real.
  5. Muestra la letra predicha en la pantalla.
