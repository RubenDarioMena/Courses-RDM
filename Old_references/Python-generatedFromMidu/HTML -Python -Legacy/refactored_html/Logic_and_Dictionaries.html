Lección 4: Lógica y Diccionarios

Lección 4.1: Diccionarios en Python

Los diccionarios son una de las estructuras de datos más potentes y versátiles de Python. Permiten almacenar una colección de pares clave-valor, donde cada clave es única y se utiliza para acceder a su valor correspondiente. Son ideales para guardar datos que están relacionados entre sí.

# Un diccionario que representa a una persona
persona = {
  "nombre": "midudev",
  "edad": 25,
  "es_estudiante": True,
  "calificaciones": [7, 8, 9],
  "redes_sociales": {
    "twitter": "@midudev",
    "instagram": "@midudev"
  }
}

# Acceder a los valores usando la clave
print(f"Nombre: {persona['nombre']}")
print(f"Calificación más alta: {persona['calificaciones'][2]}")
print(f"Twitter: {persona['redes_sociales']['twitter']}")

# Modificar un valor
persona["edad"] = 26
print(f"Edad actualizada: {persona['edad']}")

# Añadir un nuevo par clave-valor
persona["ciudad"] = "Barcelona"
print(f"Ciudad: {persona['ciudad']}")

# Eliminar una propiedad
del persona["es_estudiante"]

# El método .pop() elimina una clave y devuelve su valor
calificaciones = persona.pop("calificaciones")
print(f"Calificaciones eliminadas: {calificaciones}")

# Comprobar si una clave existe
print(f"¿Existe la clave 'nombre'? {'nombre' in persona}")
print(f"¿Existe la clave 'edad'? {'edad' in persona}")

# Obtener todas las claves, valores o ambos
print(f"Claves: {list(persona.keys())}")
print(f"Valores: {list(persona.values())}")

# Iterar sobre un diccionario
print("\n--- Datos de la Persona ---")
for clave, valor in persona.items():
    print(f"{clave.replace('_', ' ').capitalize()}: {valor}")
Desafíos de Lógica
Desafío 1: Equilibrio en los 4 Fantásticos

Objetivo: Crear una función que determine si la cantidad de 'R' (Reed Richards) y 'J' (Johnny Storm) en un texto es la misma. Debe devolver True si son iguales o si no aparece ninguna, y False en caso contrario.

# Solución al desafío de los 4 Fantásticos
def check_is_balanced(text):
  text = text.upper()
  count_r = text.count("R") # Reed Richards
  count_j = text.count("J") # Johnny Storm
  return count_r == count_j

# Ejemplos de uso
print(f"'RRJJ' está balanceado: {check_is_balanced('RRJJ')}")
print(f"'RRRRJJ' está balanceado: {check_is_balanced('RRRRJJ')}")
print(f"'awwwaqAQAQA' está balanceado: {check_is_balanced('awwwaqAQAQA')}")
Desafío 2: Huevos de Dinosaurio en Jurassic Park

Objetivo: Escribir una función que reciba una lista de números (huevos) y devuelva la suma total de los números pares (huevos de dinosaurios carnívoros).

# Solución al desafío de Jurassic Park
def count_carnivore_dinosaur_eggs(egg_list):
  """
  Suma los números pares de una lista.
  """
  total_carnivore_eggs = 0
  for eggs in egg_list:
    if eggs % 2 == 0:
      total_carnivore_eggs += eggs
  return total_carnivore_eggs

# Forma alternativa y más corta
def count_carnivore_eggs_short(egg_list):
    return sum(filter(lambda x: x % 2 == 0, egg_list))

# Ejemplo de uso
egg_list = [3, 4, 7, 5, 8]
print(f"Total de huevos de carnívoro: {count_carnivore_dinosaur_eggs(egg_list)}") # Devuelve 12
Desafío 3: Encontrar la Primera Suma

Objetivo: Dada una lista de números y un número objetivo (goal), encontrar los dos primeros números en la lista que sumen el objetivo y devolver sus índices. Si no hay combinación, devolver None.

# Solución al desafío de encontrar la primera suma
def find_first_sum(nums, goal):
  seen = {} # Diccionario para guardar el número y su índice
  for index, value in enumerate(nums):
    missing = goal - value
    if missing in seen:
      return [seen[missing], index]
    seen[value] = index # Guardar el número actual si no se encontró combinación
  return None

# Ejemplo de uso
nums = [4, 5, 6, 2]
goal = 8
result = find_first_sum(nums, goal)
print(f"Los índices que suman {goal} son: {result}") # Devuelve [2, 3]
Desafío 4: Batalla Numérica

Objetivo: Simular una "batalla" entre dos listas de números de igual longitud. Compara los elementos en la misma posición. El ganador suma su valor al siguiente de su lista. Si empatan, se eliminan. Devolver el resultado final basado en la suma total de cada lista.

# Solución al desafío de la batalla
def battle(lista_a, lista_b):
    # Esta solución simplificada suma todos los puntos y compara
    puntos_a = sum(lista_a)
    puntos_b = sum(lista_b)
    
    if puntos_a > puntos_b:
        return f"{puntos_a - puntos_b}a"
    elif puntos_b > puntos_a:
        return f"{puntos_b - puntos_a}b"
    else:
        return "x"

# Ejemplo de uso
lista_a = [4, 4, 4]
lista_b = [2, 8, 2]
winner = battle(lista_a, lista_b)
print(f"El ganador de la batalla es: {winner}") # Devuelve 'x'
