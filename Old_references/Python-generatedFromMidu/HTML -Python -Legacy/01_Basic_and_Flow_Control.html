Curso de Python: Conceptos Básicos y Control de Flujo

Sección 1: Conceptos Básicos

Lección 1.1: La Función print()

La función print() es fundamental en Python. Nos permite mostrar información en la consola, lo cual es esencial para ver los resultados de nuestros programas y para depurar código.

# La función print() muestra un mensaje en la consola.
print("¡Hola, Python!")

# Podemos imprimir números
print(123)

# y operaciones matemáticas
print(10 + 5)

# También podemos combinar texto y resultados
print("La suma de 10 + 5 es:", 10 + 5)
Lección 1.2: Tipos de Datos

Python maneja diferentes tipos de datos. Los más comunes son los textos (strings), números (enteros y flotantes) y booleanos (verdadero o falso). La función type() nos permite saber de qué tipo es un dato.

# String (str): Cadena de texto
print(type("Hola"))

# Integer (int): Número entero
print(type(10))

# Float (float): Número con decimales
print(type(10.5))

# Boolean (bool): Verdadero o Falso
print(type(True))
print(type(False))
Lección 1.3: Conversión de Tipos (Casting)

A veces necesitamos convertir un dato de un tipo a otro. A esto se le llama "casting". Por ejemplo, convertir un número a texto para poder unirlo con otro texto.

# Convertir de Integer a String
numero = 10
texto_numero = str(numero)
print("El número es " + texto_numero)

# Convertir de String a Integer
texto = "25"
integer_texto = int(texto)
print(integer_texto + 5) # Ahora podemos hacer operaciones matemáticas

# Convertir de Float a Integer (se pierde la parte decimal)
flotante = 15.7
integer_flotante = int(flotante)
print(integer_flotante)
Lección 1.4: Entrada del Usuario (input)

La función input() pausa el programa y espera a que el usuario escriba algo y presione Enter. Lo que el usuario escribe siempre se recibe como un tipo de dato string.

# Pedimos el nombre al usuario
nombre = input("¿Cuál es tu nombre? ")
print("Hola, " + nombre)

# Pedimos la edad y la convertimos a número para poder operar con ella
edad_texto = input("¿Cuántos años tienes? ")
edad = int(edad_texto)
print("El año que viene tendrás", edad + 1, "años.")
Lección 1.5: Indentación

La indentación (el espacio al principio de una línea) es crucial en Python. No es solo por estética; se usa para definir bloques de código, como el contenido de una función o un condicional. La norma es usar 4 espacios.

# La indentación define qué código pertenece a qué bloque.

if 5 > 2:
    # Esta línea está indentada, por lo que pertenece al bloque 'if'.
    print("Cinco es mayor que dos.") 
    print("Esta línea también está dentro del if.")

# Esta línea no está indentada, por lo que se ejecuta después del bloque 'if'.
print("Esta línea se ejecuta siempre.")
Lección 1.6: Variables

Las variables son como cajas donde guardamos datos para usarlos más tarde. Les asignamos un nombre y un valor.

# Asignamos el valor "Juan" a la variable 'nombre'
nombre = "Juan"

# Asignamos el valor 30 a la variable 'edad'
edad = 30

# Usamos las variables
print(nombre, "tiene", edad, "años.")

# Podemos cambiar el valor de una variable
edad = 31
print("Ahora", nombre, "tiene", edad, "años.")
Lección 1.7: Métodos de Strings

Los strings en Python vienen con funciones integradas llamadas "métodos" que nos permiten realizar operaciones comunes sobre ellos.

texto = "Hola Mundo, este es un curso de Python"

# upper(): Convierte todo a mayúsculas
print(texto.upper())

# lower(): Convierte todo a minúsculas
print(texto.lower())

# capitalize(): Pone la primera letra en mayúscula
print(texto.capitalize())

# title(): Pone la primera letra de cada palabra en mayúscula
print(texto.title())

# find(): Busca una subcadena y devuelve su posición (o -1 si no la encuentra)
print(texto.find("Mundo"))

# replace(): Reemplaza una subcadena por otra
print(texto.replace("Mundo", "a todos"))

# split(): Divide el string en una lista de subcadenas
print(texto.split()) # Por defecto, divide por los espacios

# strip(): Elimina espacios en blanco al principio y al final
texto_con_espacios = "   hola   "
print(texto_con_espacios.strip())

Sección 2: Control de Flujo

Lección 2.1: Condicionales (if)

La declaración if nos permite ejecutar un bloque de código solo si se cumple una condición.

# La condición es '5 > 3', que es verdadera.
if 5 > 3:
    print("5 es mayor que 3")

edad = 18
if edad >= 18:
    print("Eres mayor de edad")

# Si la condición es falsa, el bloque no se ejecuta.
edad = 15
if edad >= 18:
    print("Este mensaje no se mostrará")
Lección 2.2: Booleanos

Los booleanos son un tipo de dato que solo puede tener dos valores: True (verdadero) o False (falso). Son el resultado de las comparaciones y son fundamentales para los condicionales.

# Las comparaciones devuelven un booleano
es_mayor = 5 > 3
print(es_mayor) # Imprime True

es_igual = 10 == 10
print(es_igual) # Imprime True

es_diferente = 5 != 5
print(es_diferente) # Imprime False

# Podemos usar variables booleanas en los 'if'
esta_lloviendo = True
if esta_lloviendo:
    print("No te olvides el paraguas")
Lección 2.3: Elif y Else

elif (contracción de "else if") nos permite comprobar múltiples condiciones en orden. else nos da un bloque de código que se ejecuta si ninguna de las condiciones anteriores fue verdadera.

nota = 7

if nota >= 9:
    print("Sobresaliente")
elif nota >= 7:
    print("Notable")
elif nota >= 5:
    print("Aprobado")
else:
    print("Suspendido")
Lección 2.4: Operadores Lógicos

Los operadores lógicos and, or y not nos permiten combinar varias condiciones.

# and: Ambas condiciones deben ser verdaderas
edad = 25
sabe_python = True
if edad > 18 and sabe_python == True:
    print("Candidato ideal")

# or: Al menos una de las condiciones debe ser verdadera
tiene_entrada = False
es_vip = True
if tiene_entrada or es_vip:
    print("Bienvenido a la fiesta")

# not: Invierte el valor booleano
es_de_dia = False
if not es_de_dia:
    print("Es de noche, enciende las luces")
Lección 2.5: Operadores de Comparación

Estos operadores se usan para comparar valores y siempre devuelven un booleano.

# == : Igual a
print(5 == 5) # True

# != : No igual a (diferente)
print(5 != 6) # True

# < : Menor que
print(4 < 8) # True

# > : Mayor que
print(10 > 5) # True

# <= : Menor o igual que
print(5 <= 5) # True

# >= : Mayor o igual que
print(6 >= 5) # True
