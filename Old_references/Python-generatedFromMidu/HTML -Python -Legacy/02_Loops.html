Lección 3: Bucles en Python

01 - Bucle `while`

¿Qué es un bucle `while`?

Permite ejecutar un bloque de código repetidamente mientras se cumpla una condición.

Bucle con condición simple

contador = 0
while contador <= 5:
  print(contador)
  contador += 1 # ¡Muy importante para evitar bucles infinitos!

Uso de `break`

La palabra clave `break` permite salir forzosamente de un bucle.

contador = 0
while True:
  print(contador)
  contador += 1
  if contador == 5:
    break # Sale del bucle aquí

Uso de `continue`

La palabra clave `continue` salta la iteración actual y continúa con la siguiente.

contador = 0
while contador < 10:
  contador += 1
  if contador % 2 == 0:
    continue # Si es par, no imprime y sigue a la siguiente iteración
  print(contador)

Cláusula `else` en `while`

El bloque `else` se ejecuta cuando la condición del `while` deja de ser verdadera (es decir, el bucle termina de forma natural, sin un `break`).

contador = 0
while contador < 5:
  print(contador)
  contador += 1
else:
  print("El bucle ha terminado")

02 - Bucle `for`

¿Qué es un bucle `for`?

Permite iterar sobre los elementos de una secuencia (como una lista, tupla, diccionario, conjunto o cadena).

Iterar una lista

frutas = ["manzana", "pera", "mandarina"]
for fruta in frutas:
  print(fruta)

Iterar con `enumerate()`

Para obtener tanto el índice como el valor durante la iteración.

frutas = ["manzana", "pera", "mandarina"]
for idx, value in enumerate(frutas):
  print(f"El índice es {idx} y la fruta es {value}")

Comprensión de Listas (List Comprehension)

Una forma concisa de crear listas. El siguiente ejemplo crea una lista con los números pares del 1 al 6.

pares = [num for num in [1, 2, 3, 4, 5, 6] if num % 2 == 0]
print(pares) # Salida: [2, 4, 6]

03 - La función `range()`

¿Qué es `range()`?

Crea una secuencia inmutable de números. Es muy útil para ejecutar un bucle `for` un número específico de veces.

Sintaxis de `range()`

  • range(fin): Secuencia desde 0 hasta fin - 1.
  • range(inicio, fin): Secuencia desde inicio hasta fin - 1.
  • range(inicio, fin, paso): Secuencia desde inicio hasta fin - 1, incrementando en paso.

Ejemplos

# Imprimir números del 0 al 9
for num in range(10):
  print(num)

# Imprimir números del 10 al 1 (orden inverso)
for num in range(10, 0, -1):
  print(num)

04 - Funciones

¿Qué son las funciones?

Son bloques de código reutilizables y parametrizables que realizan una tarea específica. Ayudan a organizar el código, hacerlo más legible y evitar la repetición.

Definición y llamada

# Definición de una función con parámetros y valor de retorno
def sumar(a, b):
  """Esta función recibe dos números y devuelve su suma."""
  return a + b

# Llamada a la función
resultado = sumar(5, 3)
print(resultado) # Salida: 8

Argumentos variables

*args permite pasar un número variable de argumentos posicionales, que se reciben como una tupla. **kwargs permite pasar argumentos de palabra clave, que se reciben como un diccionario.

def mostrar_info(*args, **kwargs):
    print("Argumentos posicionales:", args)
    print("Argumentos de palabra clave:", kwargs)

mostrar_info(1, "hola", nombre="Ana", edad=30)
