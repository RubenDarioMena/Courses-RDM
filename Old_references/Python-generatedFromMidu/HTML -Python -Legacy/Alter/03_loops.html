Lección 3: Bucles y Funciones

En esta lección dominaremos las estructuras que permiten repetir tareas (bucles) y organizar nuestro código en bloques reutilizables (funciones), dos de los pilares más importantes de la programación.

El Bucle `while`

Un bucle while (mientras) ejecuta un bloque de código repetidamente mientras una condición específica sea verdadera. Es ideal cuando no sabemos de antemano cuántas veces necesitamos repetir una acción.

Bucle Básico:
Veamos un bucle simple que cuenta de 0 a 5. Es crucial tener un contador (contador += 1) que cambie en cada iteración para que la condición eventualmente se vuelva falsa y así evitar bucles infinitos.

contador = 0
while contador <= 5:
  print(contador)
  contador += 1 # es super importante para evitar un bucle infinito

break para Romper el Bucle:
La palabra clave break nos permite salir de un bucle inmediatamente, sin importar si la condición principal (en este caso while True) todavía es verdadera. Es una salida de emergencia.

contador = 0
while True: # Esto crearía un bucle infinito si no fuera por el break
  print(contador)
  contador += 1
  if contador == 5:
    break # sale del bucle cuando el contador llega a 5

continue para Saltar una Iteración:
continue es diferente. No rompe el bucle, sino que ignora el resto del código de la iteración actual y salta directamente al inicio de la siguiente. En este ejemplo, si el número es par, se salta el print().

contador = 0
while contador < 10:
  contador += 1
  if contador % 2 == 0: # Si el número es par...
    continue # ...salta a la siguiente iteración sin imprimirlo.
  print(contador) # Solo se ejecuta para números impares

Ejemplo Práctico con input:
Un uso muy común de while es validar la entrada del usuario. Este bucle no dejará de pedir un número hasta que el usuario introduzca uno positivo. Además, usamos try-except para manejar el error si el usuario escribe texto en lugar de un número.

numero = -1
while numero < 0:
  try:
    numero = int(input("Escribe un número positivo: "))
    if numero < 0:
      print("El número debe ser positivo. Intenta otra vez.")
  except ValueError:
    print("Error: Debes introducir un número válido.")

print(f"¡Excelente! El número que has introducido es {numero}")

El Bucle `for`

El bucle for se utiliza para iterar sobre los elementos de una secuencia (como una lista, una cadena de texto o un rango de números). Es perfecto cuando sabes de antemano sobre qué conjunto de elementos quieres operar.

Iterar sobre Secuencias:
El uso más común es recorrer los elementos de un iterable. En cada iteración, la variable del bucle (fruta, caracter) toma el valor del siguiente elemento de la secuencia.

# Iterar una lista
frutas = ["manzana", "pera", "mandarina"]
for fruta in frutas:
  print(fruta)

# Iterar sobre una cadena de texto
cadena = "midudev"
for caracter in cadena:
  print(caracter)

enumerate() para Índice y Valor:
Si necesitas tanto la posición (índice) como el valor de cada elemento, la función enumerate() es tu mejor aliada. Devuelve ambos en cada iteración.

frutas = ["manzana", "pera", "mandarina"]
for idx, value in enumerate(frutas):
  print(f"El índice es {idx} y la fruta es {value}")

Comprensión de Listas (List Comprehension):
Python ofrece una sintaxis muy potente y concisa llamada "comprensión de listas" para crear nuevas listas a partir de iterables. Es una forma elegante de escribir un bucle for cuyo objetivo es construir una lista, a menudo con alguna condición.

# Crear una lista con todos los animales en mayúsculas
animales = ["perro", "gato", "raton", "loro", "pez", "canario"]
animales_mayus = [animal.upper() for animal in animales]
print(animales_mayus)

# Crear una lista solo con los números pares de otra lista
numeros = [1, 2, 3, 4, 5, 6]
pares = [num for num in numeros if num % 2 == 0]
print(pares)

La Función `range()`

La función range() es una herramienta extremadamente útil que genera una secuencia inmutable de números. Es el compañero perfecto para los bucles for cuando necesitas repetir una acción un número específico de veces.

Formas de usar range():
Puede tomar uno, dos o tres argumentos, dándonos un control total sobre la secuencia generada:

  • range(fin): Genera números desde 0 hasta fin - 1.
  • range(inicio, fin): Genera números desde inicio hasta fin - 1.
  • range(inicio, fin, paso): Genera números desde inicio hasta fin - 1, incrementando en cada paso. El paso puede ser negativo para ir hacia atrás.
# 1. range(fin) -> de 0 a 9
print("Del 0 al 9:")
for num in range(10):
  print(num, end=" ") # end=" " imprime en la misma línea

print("\n\n# 2. range(inicio, fin) -> de 5 a 9")
for num in range(5, 10):
  print(num, end=" ")

print("\n\n# 3. range(inicio, fin, paso) -> de 10 a 0")
for num in range(10, 0, -1):
  print(num, end=" ")
print("\n")

Uso con Guion Bajo _:
Si solo necesitas repetir una acción y no te importa el número de la iteración actual, es una convención en Python usar un guion bajo _ como nombre de la variable del bucle.

# Repetir una acción 5 veces
for _ in range(5):
  print("Esto es una repetición")

Funciones

Las funciones son bloques de código con un nombre que realizan una tarea específica. Nos permiten reutilizar código en lugar de repetirlo, haciendo nuestros programas más organizados, legibles y fáciles de mantener. Se definen con la palabra clave def.

Definición, Parámetros y return:
Una función puede recibir datos a través de parámetros (las variables entre paréntesis). Usando la palabra clave return, una función puede devolver un resultado al código que la llamó.

# Función simple sin parámetros ni retorno
def saludar():
  print("¡Hola!")

# Función con un parámetro
def saludar_a(nombre):
  print(f"¡Hola {nombre}!")

# Llamando a las funciones
saludar()
saludar_a("midudev")

# Función con dos parámetros y un valor de retorno
def sumar(a, b):
  """Este es un docstring: documenta que la función suma dos números."""
  suma = a + b
  return suma

resultado = sumar(5, 3) # Guardamos el valor devuelto en una variable
print(f"El resultado de la suma es: {resultado}")

Argumentos por Posición vs. por Clave:
Al llamar a una función, puedes pasar los argumentos en el orden en que se definieron (por posición) o especificando el nombre del parámetro al que corresponden (por clave). Usar argumentos por clave puede hacer que el código sea más claro.

def describir_persona(nombre: str, edad: int, sexo: str):
  print(f"Soy {nombre}, tengo {edad} años y me identifico como {sexo}")

# Argumentos por posición (el orden importa)
describir_persona("midudev", 39, "gato")

# Argumentos por clave (el orden no importa)
describir_persona(edad=21, sexo="hombre", nombre="madeval")

Argumentos Variables: *args y **kwargs
A veces no sabes cuántos argumentos recibirá tu función.

  • *args: Agrupa cualquier número de argumentos posicionales extra en una tupla.
  • **kwargs: Agrupa cualquier número de argumentos por clave extra en un diccionario.

# *args para un número variable de argumentos posicionales
def sumar_numeros(*args):
  print(f"Recibí los argumentos: {args}")
  suma = 0
  for numero in args:
    suma += numero
  return suma

print(sumar_numeros(1, 2, 3, 4, 5))

# **kwargs para un número variable de argumentos de clave-valor
def mostrar_informacion_de(**kwargs):
  print(f"Recibí los argumentos: {kwargs}")
  for clave, valor in kwargs.items():
    print(f"- {clave}: {valor}")

mostrar_informacion_de(nombre="pheralb", es_sub=True, is_rich=True)
