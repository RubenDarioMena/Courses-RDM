Empaquetando Código: Funciones

Una función es como una receta: tiene un nombre, necesita "ingredientes" (parámetros), y entrega un resultado (el valor de retorno).

Tu Primera Función con `def`

# 1. Definimos la función
def saludar():
    print("¡Hola! Bienvenido/a al mundo de las funciones.")
    print("Esta es una herramienta que acabas de crear.")

# 2. "Llamamos" a la función para que se ejecute
saludar()

Ingredientes: Pasando Parámetros

def saludo_personalizado(nombre):
    print(f"¡Hola, {nombre}! Qué bueno tenerte aquí.")

# Ahora podemos reutilizar la función con diferentes nombres
saludo_personalizado("Ana")
saludo_personalizado("Carlos")

El Resultado: La Sentencia `return`

def sumar(numero1, numero2):
    resultado = numero1 + numero2
    return resultado

# Llamamos a la función y guardamos el valor que nos devuelve
suma_total = sumar(10, 5)
print(f"El resultado de la suma es: {suma_total}")

¿Está en Equilibrio la Alianza?

Objetivo: Crear una función que reciba un texto y verifique si el número de letras 'R' es igual al número de letras 'J' (mayúsculas o minúsculas).

def check_is_balanced(text):
    # Convertimos todo a mayúsculas para no diferenciar
    text_upper = text.upper()
    # Contamos las apariciones de cada letra
    count_r = text_upper.count("R")
    count_j = text_upper.count("J")
    # La comparación ya devuelve True o False
    return count_r == count_j

# Pruebas
print(f"'RRJJ' está balanceado? -> {check_is_balanced('RRJJ')}")
print(f"'rJ' está balanceado? -> {check_is_balanced('rJ')}")

¡Peligro en Jurassic Park!

Objetivo: Escribe una función que reciba una lista de números (huevos por nido) y devuelva la suma de todos los números pares.

def count_carnivore_dinosaur_eggs(egg_list):
    total_carnivore_eggs = 0
    # Recorremos cada número en la lista
    for eggs in egg_list:
        # Usamos el operador módulo (%) para saber si es par
        if eggs % 2 == 0:
            total_carnivore_eggs += eggs
    return total_carnivore_eggs

# Prueba
egg_counts = [3, 4, 7, 5, 8, 10]
total = count_carnivore_dinosaur_eggs(egg_counts)
print(f"El total de huevos de carnívoro es: {total}")

El Clásico de las Entrevistas: "Two Sum"

Objetivo: Dada una lista de números y un objetivo (goal), encuentra los índices de los dos números que sumen exactamente el goal.

def find_sum_indexes(nums, goal):
    seen = {}  # Diccionario para guardar -> {valor_visto: indice_visto}
    # Usamos enumerate para obtener tanto el índice como el valor
    for index, value in enumerate(nums):
        missing = goal - value
        # Si el número que nos falta ya está en nuestro diccionario...
        if missing in seen:
            # ¡Lo encontramos!
            return [seen[missing], index]
        # Si no, guardamos el número actual y su índice.
        seen[value] = index
    return None # Si no se encuentra combinación

# Prueba
numeros = [2, 7, 11, 15]
objetivo = 9
indices = find_sum_indexes(numeros, objetivo)
print(f"Los índices que suman {objetivo} son: {indices}")
