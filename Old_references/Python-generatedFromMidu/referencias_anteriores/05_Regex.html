Módulo 05: Manipulación Avanzada de Texto (Regex) 🔎

Has llegado a una de las herramientas más potentes de la programación: las Expresiones Regulares, o Regex. Es un mini-lenguaje diseñado para la búsqueda y manipulación de patrones en el texto.

El Módulo `re`: Tu Caja de Herramientas Regex

Para usar Expresiones Regulares en Python, importamos el módulo re.

Encontrando la Primera Coincidencia con `re.search()`

import re

texto = "El veloz zorro marrón salta sobre el perro perezoso."
patron = "zorro"
coincidencia = re.search(patron, texto)

if coincidencia:
    print("¡Patrón encontrado!")
    print(f"Texto: '{coincidencia.group()}'")
    print(f"Índice: {coincidencia.start()}-{coincidencia.end()}")
else:
    print("No se encontró el patrón.")

Encontrando Todas las Coincidencias con `re.findall()`

import re

texto = "Python es genial. Me encanta programar en Python. ¡Viva Python!"
patron = "Python"
todas_las_coincidencias = re.findall(patron, texto)

print(f"Se encontraron {len(todas_las_coincidencias)} coincidencias.")
print(todas_las_coincidencias)

Los Símbolos Mágicos: Metacaracteres

Son símbolos con un significado especial: . (comodín), \d (dígito), \w (alfanumérico), \s (espacio).

import re
texto = "El pedido 45A llegó el 15-03-2023."

# Encontrar un patrón de "dígito, dígito, letra"
patron_pedido = r"\d\d\w"
print("Código encontrado:", re.search(patron_pedido, texto).group())

# Encontrar una fecha
patron_fecha = r"\d\d-\d\d-\d\d\d\d"
print("Fecha encontrada:", re.search(patron_fecha, texto).group())

Anclas: `^` (inicio) y `$` (final)

import re
texto1 = "Hola mundo"
# ¿El texto EMPIEZA con "Hola"?
if re.search(r"^Hola", texto1):
    print(f"'{texto1}' empieza con Hola.")

Especificando Repeticiones: Cuantificadores

Indican cuántas veces aparece un carácter: * (0 o más), + (1 o más), ? (0 o 1), {n} (exactamente n veces).

import re
# La 'o' debe aparecer al menos una vez
print(re.findall(r"ho+la", "hla hla hola hoola"))

# La 'u' es opcional
print(re.findall(r"colou?r", "color colour"))

# Buscar secuencias de exactamente 9 dígitos
texto = "Mis números son 123456789 y 98765"
patron_9_digitos = r"\d{9}"
print("Teléfonos válidos:", re.findall(patron_9_digitos, texto))

Creando Nuestros Propios Grupos

Conjuntos de Caracteres `[]`

Permiten definir un conjunto de caracteres válidos: [aeiou] (vocales), [a-z] (rango).

import re
texto = "gato poto roto mato"
# Buscar palabras que empiecen con 'g' o 'm' y terminen en 'ato'
patron = r"[gm]ato"
print(re.findall(patron, texto))

Grupos de Captura `()`

Agrupan partes de un patrón y "capturan" el texto coincidente.

import re
# Capturar para extraer partes de un texto
texto = "Nombre: Juan, Apellido: Pérez"
patron_datos = r"Nombre: (\w+), Apellido: (\w+)"
coincidencia = re.search(patron_datos, texto)
if coincidencia:
    nombre = coincidencia.group(1)
    apellido = coincidencia.group(2)
    print(f"Nombre: {nombre}, Apellido: {apellido}")

Desafío: Crear un Validador de Contraseñas

Usa lo aprendido para escribir una función que valide si una contraseña es segura. Debe cumplir:

  • Tener al menos 8 caracteres de longitud.
  • Contener al menos una letra minúscula ([a-z]).
  • Contener al menos una letra mayúscula ([A-Z]).
  • Contener al menos un número ([0-9]).

Pista: Puedes usar re.search() cuatro veces, una para cada regla, dentro de una función.
