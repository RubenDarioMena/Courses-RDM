Declaraciones: Las Órdenes que Damos

Una "declaración" (o statement) es simplemente una instrucción. Es una orden que le das al motor de JavaScript. Imagina que cada línea de código es una frase en un manual de instrucciones: "haz esto", "luego haz aquello".

Para que todo sea más claro (para nosotros y para el navegador), solemos escribir cada instrucción en una nueva línea y terminarla con un punto y coma (;).

alert('Hola, mundo!');
alert('¡Estoy aprendiendo JS!');

¿Y si no pongo el punto y coma? JavaScript a menudo lo añade por ti, pero es como un corrector automático que a veces se equivoca. Es una buena práctica ponerlo siempre para evitar errores raros. ¡No confíes en la magia!

Comentarios: Notas para tu "Yo" del Futuro

Los comentarios son texto que el navegador ignora por completo. Son notas adhesivas que dejas en tu código para explicar qué hace una parte, por qué tomaste una decisión o para recordarte algo. ¡Tu "yo" de dentro de seis meses te lo agradecerá!

// Esto es un comentario de una sola línea. Sirve para notas rápidas.
alert('Hola!'); // También puedes ponerlos al final de una línea.

/*
  Esto es un comentario de varias líneas.
  Es perfecto para explicaciones más
  largas y detalladas.
*/
alert('Mundo');

¿Qué es una Variable?

Una variable es como una caja con una etiqueta. Puedes guardar datos dentro (un número, un texto, lo que sea) y luego usar la etiqueta para referirte a esos datos fácilmente. Es la forma fundamental de almacenar y manejar información.

Declarando Variables: `let` y `const`

En el JavaScript moderno, tenemos dos tipos de "cajas":

  • let: Es una caja normal. Puedes cambiar su contenido cuando quieras. Úsala para valores que esperas que cambien, como la puntuación de un jugador o un contador.
  • const: Es una "caja de seguridad". Una vez que guardas algo en ella, no puedes cambiarlo. Es perfecta para valores que no deberían cambiar nunca, como una fecha de nacimiento o el valor de PI.
// Usamos let para un valor que puede cambiar.
let puntuacion = 100;
alert(puntuacion); // Muestra 100

puntuacion = 150; // ¡Podemos cambiar el valor!
alert(puntuacion); // Ahora muestra 150

// Usamos const para un valor que no cambiará.
const nombreUsuario = 'Ana';
alert(nombreUsuario);

// Si intentas esto, ¡tendrás un error en la consola!
// nombreUsuario = 'Pepe'; // TypeError: Assignment to constant variable.

¿Y qué pasa con `var`?

Verás var en código antiguo. Es la forma original de crear variables, pero se comporta de manera extraña y puede causar errores. Piensa en `var` como un teléfono de disco: funcionaba, pero hoy tenemos smartphones (`let` y `const`) que son mucho mejores. Regla simple: usa `let` y `const`, y evita `var`.

Nombrando tus Cajas

Elegir buenos nombres es un superpoder. Un buen nombre describe el contenido. La convención en JS es usar camelCase: la primera palabra en minúsculas y las siguientes empiezan con mayúscula.

  • ✔️ Bien: let userScore;, const itemsInCart;
  • ❌ Mal: let userscore;, const Itemsincart;, let x;
