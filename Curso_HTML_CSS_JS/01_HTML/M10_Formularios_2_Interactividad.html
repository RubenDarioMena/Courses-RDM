MÓDULO 10 · FORMULARIOS (PARTE 2) E INTERACTIVIDAD

Interactividad sin JavaScript

El navegador moderno ya sabe hacer mucho sin que escribas una sola línea de JS: acordeones que se expanden, modales que aparecen sobre el contenido, selectores de color y barra de progreso. En este módulo aprendes los elementos nativos que sustituyen a librerías enteras.

HTML puro Pruébalo sin salir de aquí ~75 min de lectura
1 Tipos avanzados de input

Más allá del clásico text, el navegador trae selectores dedicados para color, rango, archivo, teléfono, URL y búsqueda. Cada uno muestra una interfaz nativa adaptada al dispositivo.

TipoUso
colorSelector visual de color (rueda / hex)
rangeDeslizador numérico con min/max/step
fileSubida de archivos; con accept filtra tipos
hiddenDato invisible al usuario, enviado en el formulario
searchComo text, pero el móvil muestra botón "Buscar" y tecla de lupa
telActiva teclado numérico en móvil; valida patrón con pattern
urlValida que el contenido sea una URL absoluta
HTML · tipos avanzados 
<input type="color" value="#67E8F9">
<input type="range" min="0" max="100" value="50">
<input type="file" accept="image/*">
<input type="hidden" name="id" value="42">
<input type="search" name="q" placeholder="Buscar…">
<input type="tel" pattern="[0-9]{9}">
<input type="url" name="web">
2 datalist, output, progress & meter

Cuatro elementos poco conocidos que ahorran decenas de líneas de JS: datalist autocompleta, output muestra resultados de cálculo, progress dibuja una barra de progreso y meter muestra un valor dentro de un rango con zonas baja/alta/óptima.

<datalist>: autocompletar nativo

Se enlaza a un input mediante el atributo list. El usuario puede escribir o elegir una sugerencia del desplegable.

HTML · datalist 
<input type="search" list="sugerencias">
<datalist id="sugerencias">
  <option value="factura">
  <option value="envío">
  <option value="devolución">
</datalist>

<progress> y <meter>

progress muestra cuánto de una tarea se ha completado; meter muestra un valor dentro de un rango con zonas baja/alta/óptima.

HTML · progress & meter 
<progress value="7" max="10"></progress>

<meter value="0.6" min="0" max="1"
  low="0.3" high="0.7" optimum="0.9"></meter>
3 Acordeones nativos: details & summary

<details> crea una región plegable. <summary>, su primer hijo, es la etiqueta visible que el usuario pulsa para abrir/cerrar. Con el atributo open empieza abierto. Cero JavaScript.

HTML · details/summary 
<details open>
  <summary>¿Cómo restablezco mi contraseña?</summary>
  <p>Haz clic en "Olvidé mi contraseña" en la pantalla de login…</p>
</details>
4 Modales nativos: dialog

<dialog> es el modal nativo del navegador. showModal() lo abre como ventana flotante con backdrop y foco gestionado; close() lo cierra. En esta demo usaremos el mínimo de JS necesario para invocar estos métodos.

HTML · dialog 
<dialog id="aviso">
  <p>¡Bienvenido al centro de ayuda!</p>
  <button type="button" onclick="aviso.close()">Cerrar</button>
</dialog>

<button onclick="aviso.showModal()">Abrir modal</button>

6 Ejercicio: FAQ + formulario interactivo

Crea un archivo faq-form.html con un centro de ayuda que combine todo lo aprendido en una sola página real.

1

Crea la base

Estructura mínima del documento con un <h1> "Centro de ayuda".

2

Añade 3 acordeones FAQ

Tres <details>, cada uno con su <summary> + <p>. El primero con open.

3

Formulario de búsqueda con datalist

Un <input type="search" list="sugerencias"> con un <datalist> de 5 opciones (factura, envío, devolución…).

4

Modal nativo

Un <dialog> con un botón de cierre y, fuera, un botón que llama a dialog.showModal().

5

Añade progress y meter

Verifica en el navegador: los acordeones se expanden sin JS, el datalist sugiere, el modal flota y las barras se ven.
