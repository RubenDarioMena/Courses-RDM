Dibuja con el canvas nativo

El navegador moderno no solo renderiza HTML: expone APIs que dibujan, geolocalizan, arrastran y controlan el modo pantalla completa. Aquí abrimos el <canvas> y damos un vistazo conceptual a las demás. El canvasEs tu puerta de entrada a gráficos sin una librería.

1 El elemento <canvas>

El <canvas> es una zona rectangular donde el navegador te deja dibujar píxel a píxel usando JavaScript. No es HTML/CSS: es una superficie 2D controlada por código. Se usa para juegos, gráficos, diagramas y visualización de datos.

El molde mínimo

Declara el lienzo con width y height en píxeles. El contexto 2D es el "pincel" que pinta dentro:

HTML + JS · canvas 
<canvas id="lienzo" width="400" height="400"></canvas>

<script>
  const canvas = document.getElementById('lienzo');
  const ctx    = canvas.getContext('2d');
</script>

Formas básicas: rectángulo, texto y arco

JS · dibujo básico 
// Fondo
ctx.fillStyle = '#09080F';
ctx.fillRect(0, 0, 400, 400);

// Rectángulo violeta
ctx.fillStyle = '#A78BFA';
ctx.fillRect(20, 20, 100, 50);

// Texto cyan
ctx.font = '20px sans-serif';
ctx.fillStyle = '#00d8ff';
ctx.fillText('Click para dibujar', 130, 50);

// Círculo en el punto (x, y) con radio 10
ctx.beginPath();
ctx.arc(x, y, 10, 0, Math.PI * 2);
ctx.fill();

3 Otras APIs: visión general conceptual

El navegador expone muchas APIs nativas. Aquí las enumeramos de forma conceptual — su uso real se verá cuando tengas JavaScript disponible; por ahora solo necesitas saber que existen y qué hacen.

Geolocation

Requiere permiso

Sin permiso

Fullscreen

Pone un elemento a pantalla completa.

Sin permiso

Visibility

Detecta si la pestaña está visible o oculta.

Sin permiso

Canvas 2D

Dibuja formas, texto e imágenes pixel a pixel.

Sin permiso

localStorage

Guarda datos entre recargas. M42 · JS

Sin permiso

Con permiso vs sin permiso

Algunas APIs (Geolocation) abren un diálogo pidiendo consentimiento al usuario; otras (Canvas, Fullscreen) no lo necesitan porque no exponen datos sensibles. Conocer esta diferencia te ayuda a predecir el comportamiento de tu app.
