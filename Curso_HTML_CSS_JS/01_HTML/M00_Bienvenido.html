La idea en una imagen

Construir una web es como construir una casa

Hay tres capas, y cada lenguaje se encarga de una. Juntas forman cualquier página web que hayas visitado.

HTML es la estructura
Las paredes, el techo, las puertas. El esqueleto de la página.
CSS es la decoración
La pintura, los muebles, el estilo. Cómo se ve todo.
JavaScript es la electricidad
La luz que se enciende, el timbre que suena. Lo que hace que la casa cobre vida.
1 El navegador: tu lienzo

¿Qué es un navegador?

Un navegador (Chrome, Firefox, Safari, Edge) es un programa que lee archivos HTML, CSS y JavaScript y los transforma en la página web que ves. Es tu intérprete: tú escribes el código, el navegador lo ejecuta.

De código a pantalla

Cuando abres una página web, el navegador hace algo parecido a esto:

Lee el HTML

Descifra la estructura: qué va primero, qué es un título, qué es un párrafo.

Aplica el CSS

Decora: colores, tamaños, posiciones. Convierte el esqueleto en algo con estilo.

Ejecuta el JavaScript

Dale vida: botones que responden, datos que cambian, animaciones que se mueven.

3 Editar HTML en vivo

El navegador tiene una herramienta secreta: las DevTools (Herramientas de Desarrollador). Te permiten ver y editar el código de cualquier página en tiempo real.

Abre las DevTools

Haz clic derecho en cualquier parte de esta página → Inspeccionar (o pulsa F12 / Cmd+Option+I en Mac).

Busca la pestaña "Elements" (Elementos)

Verás el árbol HTML de esta página. Es como ver los planos de la casa.

Doble clic en cualquier texto

Edítalo. Pulsa Enter. ¡El texto de la página cambia al instante! Es temporal — al recargar vuelve, pero es tu primera edición de HTML.
