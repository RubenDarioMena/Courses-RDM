MÓDULO 08 · DATOS TABULARES

Tablas con sentido

Una tabla HTML no es para hacer el diseño de la página (eso es CSS). Una tabla es para datos tabulares: cosas que se organizan en filas y columnas con sentido. Con la estructura correcta, además, será accesible a lectores de pantalla.

Filas y columnas scope / colspan ~12 min de lectura
1 La estructura mínima

Tres etiquetas forman el esqueleto de cualquier tabla: <table> la envuelve, <tr> define cada fila, y dentro van celdas de cabecera <th> o celdas de datos <td>.

HTML · tabla mínima 
<table>
  <tr>
    <th>Planeta</th>
    <th>Diámetro (km)</th>
  </tr>
  <tr>
    <td>Mercurio</td>
    <td>4879</td>
  </tr>
  <tr>
    <td>Venus</td>
    <td>12104</td>
  </tr>
</table>
2 thead, tbody, tfoot y caption

Una tabla bien hecha divide su contenido en tres zonas semánticas: la cabecera (<thead>), el cuerpo (<tbody>) y, opcionalmente, un pie de totales (<tfoot>). El navegador puede usarlos para scroll, impresión y accesibilidad.

<caption>
título de tabla
El primer hijo de <table>. Describe de qué trata. Es lo que un lector de pantalla lee primero.
<thead>
cabecera
Envuelve las filas de cabeceras de columna. El navegador puede repetirlo en cada página al imprimir.
<tbody>
cuerpo
Envuelve todas las filas de datos. Es obligatorio, y es donde va la mayor parte del contenido.
<tfoot>
pie de tabla
Para totales, sumarios o notas. Aparece antes del tbody en el código, pero se renderiza debajo.
3 scope: que las cabeceras se entiendan

El atributo scope en <th> indica a qué se refiere esa cabecera: a una columna (col) o a una fila (row). Esto es lo que permite a un lector de pantalla anunciar "Diámetro: 4879" en lugar de solo "4879".

HTML · cabeceras con scope 
<thead>
  <tr>
    <th scope="col">Planeta</th>
    <th scope="col">Diámetro (km)</th>
  </tr>
</thead>
<tbody>
  <tr>
    <th scope="row">Mercurio</th>
    <td>4879</td>
  </tr>
</tbody>
4 Combinar celdas: colspan y rowspan

A veces una celda ocupa varias columnas (colspan) o varias filas (rowspan). Es la forma correcta de hacer cabeceras de grupo o fusionar datos.

HTML · colspan + rowspan 
<tr>
  <th colspan="2">Planetas rocosos</th>
</tr>
<tr>
  <th scope="row">Tierra</th>
  <td rowspan="2">Habitables</td>
</tr>
<tr>
  <th scope="row">Marte</th>
</tr>

No uses tablas para el layout. Aunque en los 90 se hacía así, hoy es un antipatrón: confunde a los lectores de pantalla, rompe la responsividad y complica el CSS. Para el layout usa CSS Grid o Flexbox (lo verás en el Bloque II).

5 Pruébalo aquí mismo

Una tabla completa con caption, thead, tbody, tfoot, scope y un colspan para agrupar planetas. Pulsa Ejecutar.

HTML · planetas.html 
<table>
  <caption>Datos comparativos de los planetas del Sistema Solar</caption>
  <thead>
    <tr>
      <th scope="col">Planeta</th>
      <th scope="col">Diámetro (km)</th>
      <th scope="col">Distancia al Sol (UA)</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Mercurio</th>
      <td>4879</td>
      <td>0.39</td>
    </tr>
    <tr>
      <th scope="row">Venus</th>
      <td>12104</td>
      <td>0.72</td>
    </tr>
    <tr>
      <th colspan="2">Planetas rocosos (interior)</th>
      <td>~1 UA</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <th scope="row">Total muestreado</th>
      <td colspan="2">3 entradas</td>
    </tr>
  </tfoot>
</table>
