MÓDULO 06 · LISTAS

Organiza la información con listas

Las listas son el pegamento semántico de la web: menús de navegación, pasos de una receta, términos de un glosario. En este módulo aprenderás los tres tipos que existen en HTML y cómo anidarlos sin perder el sentido.

HTML puro Pruébalo sin salir de aquí ~45 min de lectura
1 Listas no ordenadas y ordenadas

Existen dos listas para secuenciar elementos: las no ordenadas (viñetas) y las ordenadas (números). Ambas comparten el mismo hijo: la etiqueta <li> ("list item").

Lista no ordenada · <ul>

Para colecciones donde el orden no importa — ingredientes, características, etiquetas de un blog. El navegador las pinta con viñetas (•).

HTML 
<ul>
  <li>Patatas</li>
  <li>Huevos</li>
  <li>Aceite</li>
  <li>Sal</li>
  <li>Cebolla (opcional)</li>
</ul>

Lista ordenada · <ol>

Para secuencias donde el orden sí importa — pasos de una receta, un ranking, un tutorial. El navegador numera automáticamente cada <li>.

HTML 
<ol>
  <li>Pelar y cortar las patatas</li>
  <li>Freír en aceite abundante</li>
  <li>Cuajar la tortilla</li>
  <li>Servir caliente</li>
</ol>
2 Los atributos de <ol>

La etiqueta <ol> acepta tres atributos que cambian cómo se numeran los elementos. Sin tocar el HTML interior, puedes reiniciar la cuenta, invertirla o usar letras romanas.

1

start

Número por el que empieza la cuenta. Útil cuando retomas una lista interrumpida por un párrafo.

2

reversed

Cuenta hacia atrás: 5, 4, 3, 2, 1. Ideal para rankings tipo "top 10" presentados de abajo a arriba.

3

type

Cambia el estilo del marcador: 1 (números), A (mayúsculas), a (minúsculas), I (romanas), i (romanas minúsculas).

HTML · atributos de <ol> 
<!-- Empieza en 5 y usa letras mayúsculas -->
<ol start="5" type="A">
  <li>Primero desde la E</li>
  <li>Segundo, será la F</li>
</ol>

<!-- Cuenta descendente -->
<ol reversed>
  <li>El más votado</li>
  <li>El menos votado</li>
</ol>
3 Listas de definición

El tercer tipo de lista no enumera: asocia. Se usa para glosarios, metadatos, fichas técnicas. Tres etiquetas trabajan juntas y forman un "diccionario" semántico.

1

<dl> · description list

El contenedor. Envuelve todos los pares término–definición.

2

<dt> · description term

La palabra o concepto que se define. Puede ir seguido de varios <dd> si un término tiene varias acepciones.

3

<dd> · description details

La definición del término. El navegador la indenta visualmente para distinguirla.

HTML · <dl> 
<dl>
  <dt>Sartén</dt>
  <dd>Recipiente de fondo plano para freír a fuego medio.</dd>

  <dt>Espátula</dt>
  <dd>Útil de mango largo para dar la vuelta a la tortilla.</dd>

  <dt>Plato</dt>
  <dd>Cubre la sartén para voltear la tortilla sin riesgo.</dd>
</dl>
4 Anidamiento correcto

Una lista puede contener otra lista dentro de un <li>. Es el patrón clásico de los menús con submenús o de las recetas con sub-pasos. La regla de oro: la lista hija siempre va dentro del <li>, nunca como hermana directa del <li>.

HTML · anidamiento válido 
<ol>
  <li>Pelar y cortar las patatas</li>
  <li>Freír en aceite abundante</li>
  <li>Cuajar la tortilla
    <ul>                        <!-- lista hija DENTRO del <li> -->
      <li>Dar la vuelta con un plato</li>
      <li>Cocer 3 minutos por el otro lado</li>
    </ul>
  </li>                               <!-- cerrar el <li> DESPUÉS de la lista hija -->
  <li>Servir caliente</li>
</ol>

Antipatrón típico

Colocar la lista hija como hermana del <li> en lugar de dentro de él. El HTML se renderiza, pero pierde la semántica jerárquica y los lectores de pantalla ya no anuncian la relación padre–hijo.

5 Ejercicio · Receta en vivo

Vamos a juntar los tres tipos de lista en una receta real: ingredientes como <ul>, pasos como <ol> con una sub-lista anidada y el equipo como <dl>. Pulsa Ejecutar para ver cómo el navegador renderiza cada tipo.

HTML · receta.html 
<h1>Tortilla de patatas</h1>
<p>La receta más española que existe.</p>

<h2>Ingredientes</h2>
<ul>
  <li>Patatas</li>
  <li>Huevos</li>
  <li>Aceite</li>
  <li>Sal</li>
  <li>Cebolla (opcional)</li>
</ul>

<h2>Pasos</h2>
<ol>
  <li>Pelar y cortar las patatas</li>
  <li>Freír en aceite abundante</li>
  <li>Cuajar la tortilla
    <ul>
      <li>Dar la vuelta con un plato</li>
      <li>Cocer 3 minutos por el otro lado</li>
    </ul>
  </li>
  <li>Servir caliente</li>
</ol>

<h2>Equipo necesario</h2>
<dl>
  <dt>Sartén</dt>
  <dd>Fondo plano, idealmente antiadherente.</dd>
  <dt>Espátula</dt>
  <dd>Para dar la vuelta con seguridad.</dd>
  <dt>Plato</dt>
  <dd>Cubre la sartén para el volteo.</dd>
</dl>
