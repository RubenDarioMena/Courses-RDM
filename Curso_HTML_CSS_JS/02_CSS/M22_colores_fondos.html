MÓDULO 22 · COLOR

Colores y fondos

El color es el lenguaje emocional de la UI. CSS te da 5 formas de escribir el mismo color (hex, rgb, hsl, oklch, color()), 3 tipos de gradientes para pintar superficies, y un arsenal de propiedades background-* que cubren el 95% de los fondos que verás en producción.

Sin instalar nada Pruébalo en el editor ~10 min
1Los 5 formatos de color

El mismo verde #34D399 se puede escribir de cinco formas. Elige la que mejor te encaje:

#34D399
rgb(52,211,153)
hsl(160,64%,52%)
oklch(75% 0.16 162)
color()

¿Cuál usar?

hex y rgb() son los más comunes. hsl() brilla cuando quieres variantes (más claro, más oscuro) sin pensar en números raros. oklch() es el nuevo estándar moderno: perceptualmente uniforme, mejor para accesibilidad y para gradientes suaves. color() te deja especificar el espacio de color (sRGB, display-p3…).

:root {
  --brand: #34D399;                /* verde marca */
  --brand-light: hsl(160, 64%, 70%);   /* +lightness       */
  --brand-modern: oklch(75% 0.16 162);   /* nueva generación */
}
a { color: currentColor; }   /* hereda el color del padre */

currentColor es una palabra mágica: vale "el color que tenga este elemento ahora mismo". Permite que un SVG o un borde herede el color del texto sin repetirlo.

2Fondos: background-image, -size, -position y shorthand

Un fondo no es solo un color: puede ser una imagen, un gradiente, una textura. Las propiedades background-* controlan cada aspecto por separado, y la shorthand background las une en una sola línea.

.hero {
  background-color: #0f172a;                              /* color base */
  background-image: url('hero.jpg'), linear-gradient(180deg, transparent, #0f172a);
  background-size: cover, auto;                          /* cover = recorta para llenar */
  background-position: center, top;                      /* contain = muestra entera  */
  background-repeat: no-repeat, no-repeat;
  background-attachment: fixed;                          /* parallax barato        */
}

/* shorthand equivalente (en cualquier orden): */
.hero {
  background: #0f172a url('hero.jpg') center/cover no-repeat fixed;
}
3Gradientes y bordes con personalidad

Tres tipos de gradientes

Los gradientes se tratan como background-image. No son imágenes reales: el navegador los calcula al vuelo.

/* lineal: de un color a otro en una dirección */
.btn { background-image: linear-gradient(135deg, #A78BFA, #34D399); }

/* radial: del centro hacia afuera (o desde un punto) */
.spotlight { background-image: radial-gradient(circle at 30% 30%, #34D399, transparent 60%); }

/* cónico: gira alrededor de un punto (relojes, donuts, paletas) */
.rueda { background-image: conic-gradient(red, yellow, lime, cyan, blue, magenta, red); }

border-radius: de cuadrado a círculo

Una propiedad, mil formas. border-radius: 50% convierte un cuadrado en círculo. 999px te da el "pastilla" típico. Puedes redondear cada esquina con un valor distinto.

.avatar     { border-radius: 50%; }   /* círculo */
.boton      { border-radius: 999px; } /* pastilla */
.tarjeta    { border-radius: 16px 4px 16px 4px; } /* esquinas alternas */
.hoja       { border-radius: 0 50% 0 50%; }    /* forma de hoja */

border-image: bordes con textura o gradiente

Si border-color se te queda corto, border-image acepta un gradiente (o imagen) como borde. Útil para acentos finos y separadores.

.acento {
  border: 2px solid transparent;
  border-image: linear-gradient(90deg, #34D399, #A78BFA) 1;
  border-radius: 12px;
}

Combinar imagen + gradiente: la técnica del overlay

El hero real combina background-image: url('foto.jpg'), linear-gradient(...). La imagen queda abajo, el gradiente encima como capa semitransparente. Así puedes oscurecer la foto para que el texto blanco se lea sin tocar el PNG. El ejemplo del CSS de arriba hace exactamente eso: rgba(15,23,42,0.2) empieza suave y se oscurece a negro sólido al final.
