MÓDULO 23 · TIPOGRAFÍA

Tipografía web

La tipografía es jerarquía, ritmo y legibilidad. Una página con buena tipografía se lee sola; una descuidada genera fricción. Vamos a controlar fuente, tamaño, peso, interlínea y las nuevas text-wrap: balance / pretty.

Sin instalar nada Pruébalo en el editor ~9 min
1Familia, tamaño, peso, estilo

font-family con stack de fallback

Nunca pongas una sola fuente: el navegador va bajando por la lista hasta encontrar una que tenga disponible. Termina siempre con una familia genérica (sans-serif, serif, monospace) para que el sistema elija algo legible si todo falla.

body {
  font-family: "Inter", "Plus Jakarta Sans", system-ui, -apple-system, sans-serif;
}
code {
  font-family: "JetBrains Mono", ui-monospace, "SF Mono", monospace;
}

Tamaño (font-size), peso (font-weight), estilo (font-style)

Tres propiedades ortogonales. font-size acepta px, rem, em y unidades fluidas (clamp()). font-weight es numérico (100-900) o por palabras (normal/bold). font-style es normal o italic. La shorthand font los une, pero requiere orden concreto.

h1 {
  font-size: clamp(2rem, 1.5rem + 2vw, 3rem); /* fluido */
  font-weight: 700;
  font-style: normal;
}
.caption {
  font: italic 0.85rem/1.5 "Inter", sans-serif; /* shorthand: style weight size/line-height family */
}
2Fuentes propias con @font-face

Si quieres usar una fuente que el usuario no tiene instalada (Inter, Roboto, tu fuente corporativa), la sirves tú. @font-face declara una familia y le pasa los archivos. font-display controla qué pasa mientras se carga.

@font-face {
  font-family: "MiMarca";
  src: url("/fonts/marca-regular.woff2") format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap;   /* muestra fallback mientras carga */
}
.logo { font-family: "MiMarca", sans-serif; }

Valores típicos de font-display:

swap
recomendado
Muestra la fuente del sistema al instante y cambia cuando la tuya esté lista. Sin texto invisible.
fallback
híbrido
Bloquea ~100ms; si no carga, usa fallback. Si llega tarde, no cambia.
optional
mobile-first
El navegador decide: si la conexión es lenta, no muestra la fuente.
block / auto
evitar
block oculta el texto hasta 3s ("FOIT"); auto queda a criterio del navegador.
3Ritmo, espaciado y text-wrap moderno

line-height, letter-spacing, word-spacing

line-height (interlínea) controla el espacio vertical entre líneas. Sin unidad (1.6) es relativo al tamaño; con unidad (24px) es absoluto. Para cuerpo 1.5-1.7; para titulares 1.1-1.2. letter-spacing afina el aire entre letras (negativo en grandes, positivo en mayúsculas pequeñas). word-spacing solo entre palabras.

p     { line-height: 1.7; }
h1    { line-height: 1.1; letter-spacing: -0.02em; }
.eyebrow {  /* "kicker" sobre un titular */
  text-transform: uppercase;
  letter-spacing: 0.12em;
  font-size: 0.75rem;
}

text-align, text-decoration, text-transform

Las tres "decorativas": alineación (left/right/center/justify), decoración (subrayado, tachado, color y grosor) y transformación (uppercase/lowercase/capitalize). Para un look moderno, text-decoration: underline wavy currentColor queda muy limpio en enlaces.

a {
  color: #10B981;
  text-decoration: underline wavy currentColor;
  text-underline-offset: 3px;
}
.lead { text-align: center; text-transform: none; }

text-wrap: balance y pretty (lo nuevo)

Estas propiedades de CSS Text Level 4 salvan del típico titular con una palabra suelta al final. balance equilibra el ancho de cada línea en bloques cortos (titulares, h1-h3). pretty evita huérfanas en la última línea del párrafo.

h1, h2, h3 { text-wrap: balance; }
p          { text-wrap: pretty;  }
.lead      { max-width: 55ch;    }  /* longitud ideal de línea */
4Tu primer momento: escala tipográfica

Una escala tipográfica coherente es la diferencia entre un diseño que se siente "diseñado" y uno que se siente improvisado. Aquí ves h1-h6, párrafo y un .caption con la jerarquía aplicada. Cambia font-size del h1, el line-height del párrafo o el font-style del caption y pulsa Ejecutar para verlo en vivo.

CSS · #inlinePreview
#inlinePreview {
  font-family: "Georgia", serif;
  font-size: 15px;
}
#inlinePreview h1 {
  font-size: 2.5rem;
  letter-spacing: -0.02em;
  text-wrap: balance;
}
#inlinePreview p {
  line-height: 1.8;
  text-wrap: pretty;
}
#inlinePreview .caption {
  font-style: italic;
  font-size: 0.85rem;
}
