MÓDULO 26 · CUSTOM PROPS

Variables, pseudo-clases y pseudo-elementos

Las custom properties son la manera nativa de CSS de tener variables. Las pseudo-clases capturan estados (:hover, :focus) y posiciones (:nth-child). Los pseudo-elementos crean contenido que no existe en el HTML (::before, ::after). Juntos son la columna vertebral de un CSS mantenible.

Sin instalar nada Pruébalo en el editor ~12 min de lectura
iLa idea en una imagen

Las custom properties no son variables "de verdad" en el sentido de un lenguaje de programación — son valores que se evalúan en el momento en que se usan, no cuando se declaran. Esto permite que cambien con el contexto, respondan a media queries, e incluso se actualicen desde JavaScript. Los pseudo-clases y pseudo-elementos son la otra cara: selectores que apuntan a cosas que no se pueden marcar con un atributo, como "el primer hijo" o "la primera letra de un párrafo".

Custom property
--color: #34D399; color: var(--color);
Declarada con --, consumida con var(). Heredable. Soporta fallback.
Pseudo-clase
:hover · :focus · :nth-child(2n)
Apuntan a un estado o posición: el primer hijo, el par, el focus, lo que no es X.
Pseudo-elemento
::before · ::after · ::placeholder
Generan contenido donde el HTML no lo tiene. Una línea decorativa, un icono, la primera letra.
01Custom properties: --nombre y var()

Una custom property se declara con dos guiones y se consume con var(). El lugar canónico para declararlas es :root, que las hace disponibles en todo el documento:

CSS 
:root {
  --color-fondo: #0f172a;
  --color-texto: #f8fafc;
  --color-acento: #34D399;
  --radio: 12px;
  --espacio: 16px;
}

body {
  background: var(--color-fondo);
  color: var(--color-texto);
  font-family: system-ui, sans-serif;
}
button {
  background: var(--color-acento);
  border-radius: var(--radio);
  padding: var(--espacio);
}

Fallback: var(--nombre, valor)

El segundo argumento de var() es el valor que se usa si la variable no está definida. Útil para componentes que reciben tema desde afuera:

CSS 
.tarjeta {
  background: var(--tarjeta-bg, #1e293b);  /* gris oscuro si no hay tema */
  color:      var(--tarjeta-fg, #f8fafc);
  padding:    var(--tarjeta-p,  16px);
}

Las custom properties son heredables: si las declarás en :root, llegan a todo el árbol. Y son dinámicas: cambiar su valor con element.style.setProperty("--color", "red") actualiza todos los usos en vivo, sin recompilar nada.

02Pseudo-clases: estado y posición

Las pseudo-clases se escriben con dos puntos (:hover) y apuntan a un estado o una posición del elemento. No son lo mismo que las clases que escribís en el HTML: el navegador las aplica automáticamente según el contexto.

Estado del usuario

Las más usadas en cualquier UI:

CSS 
:hover     /* el cursor está encima */
:focus     /* el elemento tiene el foco (inputs, links) */
:active    /* el botón está siendo pulsado */
:disabled  /* elemento deshabilitado en un form */
:checked   /* checkbox o radio marcado */

Posición: :nth-child() y compañía

La más potente es :nth-child(). Acepta una fórmula tipo an + b o palabras clave:

CSS 
:first-child            /* el primer hijo                      */
:last-child             /* el último                           */
:nth-child(2)           /* el segundo                          */
:nth-child(even)        /* todos los pares                     */
:nth-child(odd)         /* todos los impares                   */
:nth-child(3n)          /* cada 3                              */
:nth-child(3n+1)        /* cada 3, empezando en el 1          */
:nth-last-child(2)      /* el penúltimo                        */

Para hacer una lista cebra (alternar colores en filas pares), :nth-child(even) es la solución de una sola línea.

Lógica: :not(), :is(), :where(), :has()

La nueva generación permite componer selectores con lógica:

CSS 
:not(.oculto)              /* todo lo que NO tenga .oculto    */
:is(h1, h2, h3)             /* cualquiera de los tres          */
:where(h1, h2, h3)          /* igual a :is() pero ESPECIFICIDAD CERO */
:has(img)                   /* cualquier elemento que contiene un <img> */

:where() es mágico: aplica la regla pero con especificidad 0, así que nunca gana por especificidad — solo por orden. :has() es el "parent selector" que CSS nunca había tenido.

03Pseudo-elementos: contenido que no está en el HTML

Se escriben con doble dos puntos (::before) y representan una parte del elemento que no existe como nodo en el DOM. La excepción histórica son los "legacy" de un solo dos puntos (:before, :first-line) que CSS sigue aceptando por compatibilidad.

CSS 
.boton::before {
  content: "→";                /* sin content, el pseudo-elemento no existe */
  margin-right: 8px;
  font-weight: bold;
}

p::first-letter {
  font-size: 2.5em;            /* letra capital tipo "drop cap" */
  float: left;
  margin-right: 6px;
  color: #34D399;
}

::selection {                  /* color del texto seleccionado por el usuario */
  background: #34D399;
  color: #06120B;
}

input::placeholder {            /* el texto de ayuda dentro de un input vacío */
  color: #94a3b8;
  font-style: italic;
}

Regla fundamental: ::before y ::after necesitan la propiedad content para existir. Aunque sea content: "" (un string vacío) — si no, el pseudo-elemento no se renderiza.

04Tu primer momento: tema claro/oscuro + lista cebra

El bloque de la derecha aplica estilos al preview. Después abrí el playground completo para combinar HTML, CSS y JS — el JS de este módulo es una sola línea que alterna la clase del tema.

CSS 
/* === tema con custom properties === */
#themed {
  padding: 20px;
  border-radius: 12px;
  background: #f8fafc;
  color: #0f172a;
  border: 2px solid #34D399;
  transition: background 0.3s, color 0.3s;
}
#themed.oscuro {
  background: #0f172a;
  color: #f8fafc;
}
#themed .acento { color: #10B981; font-weight: 600; }

/* === lista cebra con :nth-child(even) === */
#zebralist {
  list-style: none;
  margin: 0;
  padding: 0;
  width: 100%;
  max-width: 320px;
  font-family: system-ui, sans-serif;
}
#zebralist li {
  padding: 10px 14px;
  background: #f1f5f9;
  color: #0f172a;
  border-bottom: 1px solid #e2e8f0;
}
#zebralist li: nth-child(even) {
  background: #34D399;
  color: #06120B;
  font-weight: 600;
}
#zebralist li: :before {
  content:  "→ ";
  color: #10B981;
  font-weight: bold;
}

3 detalles que dan superpoderes

1

Las custom properties se actualizan en vivo

JS: document.documentElement.style.setProperty("--color-acento", "#A78BFA") cambia TODOS los usos de esa variable en la página al instante. Es la base de los temas dinámicos.

2

:where() tiene especificidad 0

Sirve para escribir reglas base sin "ganar" el partido de la especificidad. Ideal para resets y para mantener un sistema fácil de sobrescribir.

3

::before necesita content

Sin la propiedad content, el pseudo-elemento no existe aunque escribas todo lo demás. Es el único caso donde CSS se "salta" una regla entera.
