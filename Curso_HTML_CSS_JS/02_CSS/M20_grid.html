MÓDULO 20 · GRID

CSS Grid: layout bidimensional

Flexbox organiza en una dimensión (fila O columna). CSS Grid organiza en dos a la vez: filas Y columnas. Con grid-template-areas dibujas el layout con un mapa legible como un cómic.

Sin instalar nada Pruébalo en el editor ~10 min
1De Flexbox (1D) a Grid (2D)

Por qué existe Grid si ya tenemos Flexbox

Flexbox es perfecto cuando quieres una dirección principal: una fila de tarjetas, una columna de menú, una barra de navegación. Pero en cuanto el layout reparte zonas en filas Y columnas a la vez (cabecera, sidebar, contenido, footer), Flexbox se vuelve frágil. Ahí entra Grid: divides la página en una rejilla explícita y le dices a cada hijo en qué celda vive.

El vocabulario de Grid

Contenedor
display: grid
El elemento con display: grid. Define el contexto de rejilla.
Tracks
grid-template-columns
Las líneas invisibles que dividen filas y columnas. Tú defines cuántas y de qué tamaño.
Cells / Áreas
grid-area
Cada intersección fila/columna. Aquí es donde vive un item.
Gaps
gap: 1rem
El espacio entre tracks. Más limpio que añadir margin a cada hijo.
2Las 4 propiedades que importan

Con cuatro propiedades controlas el 90% de los layouts. Son estas:

Anatomía de una rejilla
.contenedor {
  display: grid;                       /* 1. activar grid */
  grid-template-columns: 200px 1fr 200px; /* 2. columnas    */
  grid-template-rows: auto 1fr 60px;   /* 3. filas       */
  gap: 1rem;                          /* 4. espacio     */
}

Unidades clave: fr y repeat()

La unidad fr (fraction) reparte el espacio sobrante proporcionalmente. 1fr 2fr 1fr = la columna central ocupa el doble que las laterales. repeat(3, 1fr) es atajo para "1fr 1fr 1fr" — y repeat(auto-fit, minmax(220px, 1fr)) te da un grid responsivo sin una sola media query.

.galeria {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 16px;
}
3grid-template-areas: el layout legible

Esta es la joya de Grid. En lugar de contar líneas (grid-column: 1 / 3), dibujas el layout con palabras. Cada string es una fila, cada palabra es un área. Mismas palabras en celdas contiguas las fusionan.

.contenedor {
  display: grid;
  grid-template-columns: 200px 1fr 200px;
  grid-template-rows: 80px 1fr 60px;
  grid-template-areas:
    "header header header"
    "asideL main asideR"
    "footer footer footer";
  gap: 1rem;
  min-height: 100vh;
}

.header  { grid-area: header;  }
.aside-l { grid-area: asideL;  }
.main    { grid-area: main;    }
.aside-r { grid-area: asideR;  }
.footer  { grid-area: footer;  }

Posicionar con líneas: grid-column / grid-row

Cuando quieres más control, posicionas el item por las líneas (numeradas desde 1) o usando span N para ocupar N tracks. Útil cuando no quieres nombrar áreas o cuando un item solo ocupa parte de la rejilla.

.destacado {
  grid-column: 2 / 4;      /* de la línea 2 a la 4 (ocupa 2 cols) */
  grid-row: 1 / span 2;  /* desde línea 1, ocupa 2 filas     */
}

subgrid: heredar la rejilla del padre

Hasta Grid nivel 2, un grid anidado creaba su propia rejilla y los hijos no se alineaban con las columnas del padre. subgrid permite que un hijo herede los tracks del grid padre — útil para alinear cards dentro de una columna del layout principal.

.card-list {
  display: grid;
  grid-template-columns: subgrid;  /* hereda cols del padre */
  grid-column: span 2;
}

Alineación: justify-items y align-items

Deciden cómo se alinean los items dentro de su celda. justify-items = eje horizontal, align-items = vertical. Valores: start, center, end, stretch (por defecto). Para un item puntual: justify-self / align-self.

.contenedor { justify-items: center; align-items: stretch; }
.item-especial { justify-self: end; }
4Tu primer momento: el "Santo Grial"

El Santo Grial del layout (header + sidebar izq + main + sidebar der + footer) era una pesadilla con floats. Con Grid y grid-template-areas se dibuja en un mapa. Cambia las áreas y pulsa Ejecutar para ver cómo se reorganiza la rejilla sin tocar el HTML.

CSS · .contenedor
#inlinePreview {
  /* cambia estas áreas y vuelve a ejecutar */
  grid-template-columns: 120px 1fr 120px;
  grid-template-rows: 60px 1fr 50px;
  grid-template-areas:
    "header header header"
    "asideL main asideR"
    "footer footer footer";
  gap: 8px;
}
