Flexbox: layout unidimensional

Flexbox es el modelo de layout que te ahorra horas: con display: flex conviertes un contenedor en una máquina de alinear, distribuir y centrar. Trabaja en una dimensión (fila o columna) y eso lo hace perfecto para navbars, tarjetas y barras de herramientas.

Una dimensión Prueba los toggles ~14 min de lectura
1Los dos ejes: main y cross

Flexbox trabaja con dos ejes. Entenderlos es entender el 80% de todo lo demás.

Eje principal · main axis
La dirección en la que se colocan los hijos por defecto. Lo decides con flex-direction: row | column. Aquí se aplican justify-content y gap.
Eje transversal · cross axis
Perpendicular al principal. Aquí se aplican align-items, align-content y align-self. Centrar verticalmente es alinear en este eje.
.contenedor {
  display: flex;             /* activa flexbox          */
  flex-direction: row;       /* main = horizontal        */
  justify-content: space-between;  /* main axis: separar      */
  align-items: center;       /* cross axis: centrar     */
  gap: 16px;               /* espacio entre hijos      */
}
2Propiedades y patrones del día a día

Del contenedor (parent)

.nav {
  display: flex;
  flex-direction: row | column;
  flex-wrap: nowrap | wrap;
  justify-content: flex-start | center | space-between | space-around;
  align-items: stretch | center | flex-start | flex-end;
  gap: 16px;
}

De los hijos (items)

.item {
  flex-grow: 1;     /* crece si sobra sitio  */
  flex-shrink: 1;   /* encoge si falta sitio */
  flex-basis: auto;
  flex: 1;         /* shorthand: 1 1 0%  */
  align-self: center;
  order: 0;        /* reordena sin tocar HTML */
}

4 patrones que resuelven casi todo

/* 1. Centrar cualquier cosa */
.padre { display: flex; justify-content: center; align-items: center; }

/* 2. Navbar: logo izq, menú der */
.navbar { display: flex; justify-content: space-between; align-items: center; }
.menu   { display: flex; gap: 24px; }

/* 3. Columnas iguales */
.grid { display: flex; gap: 16px; }
.col  { flex: 1; }

/* 4. Footer pegado al fondo */
.card   { display: flex; flex-direction: column; }
.footer { margin-top: auto; }

3 hábitos que te harán un maestro de Flexbox

1

Usa gap en lugar de márgenes

Para separar hijos dentro de un flex container, gap es más limpio que margin-right en cada hijo: no genera el último espacio fantasma.

2

Centra con margin: auto en el hijo

Para centrar un solo hijo en un eje, no cambies el contenedor: aplica margin-left: auto o margin: auto al hijo concreto.

3

Flexbox es unidimensional

Flexbox es genial para una fila o columna. Para dos dimensiones (filas y columnas a la vez) salta a Grid, que verás en el siguiente módulo.
