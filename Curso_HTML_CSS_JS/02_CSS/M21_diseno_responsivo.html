MÓDULO 21 · RESPONSIVE

Diseño responsivo

Una página responsiva se ve bien en un móvil de 360px, en una tablet de 768px y en un monitor 4K — con el mismo HTML. CSS te da las herramientas: @media para los saltos, vw/vh/clamp() para tamaños fluidos, y srcset/<picture> para que las imágenes manden la versión correcta al navegador.

Sin instalar nada Pruébalo en el editor ~12 min
1El meta viewport y los @media

<meta viewport> (repaso rápido)

Sin esta línea, los móviles renderizan tu página como si fuera un escritorio de 980px y la缩小 toda para que entre. Es obligatorio en cualquier página responsiva. Va en el <head>:

<meta name="viewport" content="width=device-width, initial-scale=1">

@media y mobile-first

Una media query aplica un bloque de CSS solo cuando se cumple una condición (ancho, alto, orientación, prefers-color-scheme…). La filosofía mobile-first: escribe primero los estilos para móvil, y luego añade breakpoints con min-width que añaden complejidad conforme la pantalla crece. Es lo contrario de "diseñar para desktop y restar con max-width".

/* base: móvil */
.nav { flex-direction: column; }

/* tablet ≥ 768px */
@media (min-width: 768px) {
  .nav { flex-direction: row; }
}

/* desktop ≥ 1024px */
@media (min-width: 1024px) {
  .container { max-width: 1200px; margin: 0 auto; }
}
2Unidades de viewport y tamaño fluido

vw, vh, vmin, vmax

Las unidades vw/vh son relativas al viewport: 1vw = 1% del ancho de la ventana, 1vh = 1% del alto. vmin toma el menor entre ancho y alto, vmax el mayor — útiles para elementos que deben escalar con la pantalla (un hero a pantalla completa, un banner…).

.hero   { min-height: 100vh; }   /* pantalla completa */
.anuncio { width: 50vmin; }  /* mitad del lado más corto */
.texto  { font-size: 4vmax; } /* escala con el lado más largo  */

Tipografía fluida con clamp(), min(), max()

clamp(MIN, FLUIDO, MAX) devuelve un valor que crece con el viewport, pero acotado entre MIN y MAX. La fórmula clásica con vw + rem te da tipografía que escala sin saltos:

h1 {
  font-size: clamp(1.25rem, 1rem + 2vw, 2rem);
  /* 20px mínimo · crece 2% del viewport · máximo 32px */
}
.ancho { width: min(100% - 32px, 800px); }  /* nunca más ancho que 800px */
3Imágenes responsivas: que el navegador pida la correcta

Este módulo es donde aparece por fin el sistema de imágenes que se referencia desde M07 y M14. Sirve para no enviar una foto de 4K a un móvil o servir un PNG gigante donde bastaba un WebP pequeño.

srcset
srcset="a.jpg 1x, b.jpg 2x"
Lista de imágenes con su densidad. El navegador elige la adecuada según el píxel-ratio del dispositivo.
sizes
sizes="(min-width:768px) 50vw, 100vw"
Le dice al navegador cuánto ocupará la imagen para que calcule qué fuente descargar.
<picture> + <source>
<source media="..." srcset="...">
Permite recorte o formato distinto por breakpoint: WebP moderno + JPG fallback, o imagen cuadrada en móvil y panorámica en desktop.
object-fit + aspect-ratio
object-fit: cover; aspect-ratio: 4/3;
Para que una imagen ocupe una caja sin deformarse: cover recorta, contain muestra entera, aspect-ratio fija la proporción.
<picture>
  <source media="(max-width: 767px)" srcset="movil.jpg 1x, movil-retina.jpg 2x">
  <source media="(min-width: 768px)" srcset="desktop.jpg">
  <img src="desktop.jpg" alt="Producto"
       style="object-fit:cover; aspect-ratio: 4/3; width:100%">
</picture>
4Tu primer momento: tarjeta responsiva

Una tarjeta de producto debe apilarse verticalmente en móvil (imagen arriba, texto abajo) y colocarse horizontal en desktop (imagen izq, texto der). Aquí ves el resultado final. Cambia el flex-direction en el código y pulsa Ejecutar para alternar entre los dos layouts sin tocar el HTML.

CSS · .tarjeta-producto
#inlinePreview {
  /* cambia a row y verás la card horizontal; a column y vuelve vertical */
  flex-direction: row;
  gap: 20px;
  align-items: center;
}
#inlinePreview .pv-img { width: 200px; aspect-ratio: 1/1; }
