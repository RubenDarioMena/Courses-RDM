¿Qué es CSS y cómo funciona?

CSS es el lenguaje que viste a la web. Si HTML son los huesos, CSS es la piel, los colores, los tamaños, el espacio. Sin CSS, la web sería una página de texto en blanco. Con CSS, todo lo que ves tiene su lugar y su estilo.

Sin instalar nada Pruébalo en el editor ~10 min de lectura
1El lenguaje de presentación

Una definición sencilla

CSS (del inglés Cascading Style Sheets u Hojas de Estilo en Cascada) es el lenguaje que controla cómo se ve una página web. Mientras HTML pone la estructura (qué aparece), CSS decide la presentación: el color, el tamaño, la posición, la fuente, los espacios… todo.

Vive en cada navegador moderno y no necesita instalación: es simplemente texto que escribes en un archivo .css y se aplica a tu HTML. Es la capa de presentación de la web.

Las tres capas de la web

Una página web siempre se construye sobre tres capas:

Estructura · HTML
<h1>Hola</h1>
Define qué elementos aparecen: títulos, párrafos, botones, imágenes.
Presentación · CSS
h1{color:tomato}
Define cómo se ven esos elementos: color, tamaño, posición, espacio.
Comportamiento · JS
h1.onclick=...;
Define qué hacen cuando alguien interactúa con ellos.
2La sintaxis: selector + declaraciones

Cualquier regla CSS tiene dos partes: un selector que dice a qué elementos apuntar, y un bloque de declaraciones con las propiedades que vas a aplicar. Así de simple.

Estructura de una regla CSS 
h1 {
  color: tomato;
  font-size: 32px;
}

/*  selector    bloque de declaraciones          */
/*  h1       →  a qué elementos se aplica       */
/*  color    →  una propiedad                   */
/*  tomato   →  el valor de esa propiedad       */

Cada línea dentro del bloque es una declaración: propiedad: valor; y se cierra siempre con punto y coma. Los dos puntos separan la propiedad del valor. Las llaves agrupan todas las declaraciones que van juntas.

3Selectores y combinadores

El selector es la parte más importante de CSS: decide a qué se le aplica el estilo. Hay muchos tipos — estos son los que vas a usar a diario.

Selector de tipo

Apunta a todos los elementos de un tipo concreto. El más simple.

p { line-height: 1.6; }   /* todos los párrafos */
a  { text-decoration: none; }  /* todos los enlaces */

Selector de clase (.clase)

Apunta a elementos que tienen un atributo class concreto. Empiezan con un punto. Los puedes usar en tantos elementos como quieras.

.destacado { color: #34D399; font-weight: bold; }

HTML: <p class="destacado">...</p>

Selector de ID (#id)

Apunta a un único elemento con un id concreto. Empiezan con una almohadilla. Solo puede haber un elemento con ese ID por página.

#cabecera { background: #09080F; }

HTML: <header id="cabecera">...</header>

Selector universal (*)

Apunta a todos los elementos. Útil para resets o aplicar estilos base.

* { margin: 0; padding: 0; }

Selector de atributo

Apunta a elementos que tienen un atributo concreto, o un valor concreto de ese atributo.

[type]           { font: inherit; }
[type="checkbox"] { width: 18px;  }
a[href^="https"] { color: green;   } /* empiece por https */

Combinadores

Los selectores se pueden combinar para apuntar a elementos según su relación: descendientes, hijos, hermanos…

div p   {}   /* p dentro de div (en cualquier nivel) — DESCENDIENTE */
div > p   {}   /* p HIJO directo de div                            */
div + p   {}   /* p hermano ADYACENTE (justo después de div)         */
div ~ p   {}   /* todos los p HERMANOS posteriores a div            */

¡Hola, soy CSS!

3 formas de incluir CSS

Antes de terminar, lo básico indispensable. Hay tres maneras de meter CSS en tu HTML:

1

Externo (recomendado)

Un archivo .css separado vinculado desde HTML. Se cachea en el navegador y reutilizas entre páginas.

<link rel="stylesheet" href="styles.css">
2

Interno

Dentro de <style> en el <head>. Útil para una sola página o prototipar.

<style> p { line-height: 1.6; } </style>
3

Inline (evitar salvo muy alta prioridad)

Dentro del atributo style del propio elemento. Útil sólo para pruebas rápidas — no es mantenible.

<p style="color:tomato;">...</p>
