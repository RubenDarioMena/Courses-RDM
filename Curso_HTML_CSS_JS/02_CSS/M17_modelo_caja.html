MÓDULO 17 · BOX MODEL

El modelo de caja

Todo en CSS es una caja. Una caja con contenido, padding, borde y margin. Entender cómo se miden estas cuatro capas — y decidir tú cuándo border cuenta para el tamaño — es la diferencia entre un layout predecible y una pesadilla con la regla.

4 capas anidadas border-box vs content-box ~14 min de lectura
1Las cuatro capas de la caja

Cada elemento se representa como una caja con cuatro áreas, de dentro hacia fuera:

margin · espacio exterior (separa de otros)
border · el borde visible
padding · espacio interior (entre borde y contenido)
content · el contenido real (texto, imagen…)

En el navegador, abre DevTools y selecciona cualquier elemento: abajo verás el diagrama del box model con los cuatro rectángulos superpuestos. Es la mejor forma de visualizarlo.

.tarjeta {
  width:  300px;     /* content */
  padding: 24px;      /* aire interior */
  border:  2px solid #34D399;
  margin:  16px;      /* separación exterior */
}
2box-sizing: la decisión clave

content-box (por defecto, casi siempre problemático)

El width se aplica solo al content. Padding y border se suman encima. Una caja de width: 300px; padding: 24px; border: 2px; ocupa en realidad 300 + 24*2 + 2*2 = 352px. Si tu grid espera 300, se rompe.

border-box (el que usarás siempre)

El width incluye content + padding + border. Si pides width: 300px, obtienes 300px totales. Es mucho más predecible. Casi todos los resets empiezan con esta regla:

*, *::before, *::after {
  box-sizing: border-box;
}
3Unidades, shorthands y colapso de márgenes

Shorthands de margin, padding y border

Las propiedades shorthand aceptan de 1 a 4 valores, en el orden arriba · derecha · abajo · izquierda (sentido horario):

.caja {
  padding: 10px;                /* los 4 lados */
  margin:  10px 20px;            /* vertical | horizontal */
  border:  2px dashed #34D399;   /* grosor estilo color */
}
.caja { padding: 5px 10px 15px 20px; }  /* top right bottom left */

Colapso de márgenes verticales

Cuando dos elementos hermanos tienen margin-top y margin-bottom, no se suman: gana el mayor. Esto es histórico y a veces sorprendente. La solución moderna es usar gap con flexbox o grid, o aplicar solo margin-bottom.

.a { margin-bottom: 30px; }
.b { margin-top:    20px; }
/* entre .a y .b solo hay 30px (el mayor), no 50px */

overflow: qué pasa cuando el contenido se desborda

Controla qué hacer cuando el contenido es más grande que la caja. Los valores: visible (se sale), hidden (se corta), scroll (siempre muestra barras), auto (barras solo si hace falta).

4Tu primer momento: la tarjeta de perfil

Esta tarjeta tiene width: 260px; padding: 18px; border: 4px. Pulsa los botones y observa el cambio de tamaño: con content-box la caja crece hasta 260 + 36 + 8 = 304px. Con border-box se queda en 260 — porque el padding y el border se "comen" el content.

CSS · cambia box-sizing 
.profile-card {
  width: 260px;
  padding: 18px;
  border: 4px solid #10B981;
  box-sizing: content-box;
}

3 detalles del modelo de caja que ahorran horas

1

Reset box-sizing al inicio

Aplica * { box-sizing: border-box } en tu primer archivo CSS. Te olvidarás para siempre del problema "mi caja se sale del grid".

2

Usa rem para espaciado

Para padding y margin prefiere rem sobre px. Escala con la fuente del navegador y respeta la accesibilidad.

3

Sustituye margin-top por gap

Cuando uses flexbox o grid, pon el espacio en el contenedor con gap. Evitas el colapso y el CSS queda más limpio.
