01Container queries y propiedades lógicas

Las container queries son media queries que responden al tamaño del contenedor, no del viewport. Son el cambio más importante de CSS en los últimos cinco años: por fin podemos hacer componentes verdaderamente reutilizables.

CSS 
.galeria {
  container-type: inline-size;
  container-name: galeria;
}

@container galeria (min-width: 400px) {
  .tarjeta {
    display: grid;
    grid-template-columns: 1fr 2fr;
    gap: 16px;
  }
}

Propiedades lógicas: margin-inline, padding-block

En vez de pensar en "izquierda" y "derecha", pensá en "inicio" y "fin" del bloque. Las propiedades lógicas se adaptan solas al modo de escritura (LTR, RTL):

CSS 
.tarjeta {
  margin-inline:  auto;     /* centra horizontalmente sin importar RTL */
  padding-block:  20px;     /* arriba + abajo */
  padding-inline: 24px;     /* izquierda + derecha (en LTR) */
  border-inline-start: 4px solid #34D399;  /* borde del lado del inicio */
}

Si alguna vez tu sitio necesita soportar árabe o hebreo, estas propiedades te ahorran un dolor de cabeza enorme. Y aunque no lo necesites, son más legibles: margin-inline se lee como "el margen horizontal", sin importar de qué lado.

02CSS Nesting nativo y BEM

El nesting nativo (sin preprocesador) ya funciona en todos los navegadores modernos. Se anida con &, que apunta al selector padre. Combinado con la metodología BEM para nombrar, el resultado es CSS legible y sin colisiones.

CSS 
/* === BEM: bloque__elemento--modificador === */
.tarjeta {
  background: #1e293b;
  border-radius: 12px;
  padding: 16px;

  &__titulo {
    font-size: 1.25rem;
    margin-bottom: 8px;
    color: #f8fafc;
  }
  &__boton {
    background: #34D399;
    color: #06120B;
    border: 0;
    border-radius: 8px;
    padding: 10px 18px;
    cursor: pointer;
    transition: transform 0.2s ease;

    &:hover { transform: scale(1.05); }
    &--destacado { background: #fbbf24; }
  }
}

BEM = Bloque (la cosa en sí) + Elemento (parte del bloque) + Modificador (variante). Ejemplo: .tarjeta (bloque), .tarjeta__titulo (elemento), .tarjeta__boton--destacado (modificador). El doble guion bajo separa bloque de elemento; el doble guion, el modificador. No hay ambigüedad, no hay colisiones, no hay guerras de especificidad.

03@layer y el fin de las guerras de especificidad

@layer introduce capas explícitas en la cascada. La regla es simple: gana la última capa declarada, sin importar la especificidad de los selectores que tiene adentro. Eso te permite escribir utilities que sobrescriben componentes sin tener que recurrir a !important.

CSS 
@layer reset, base, components, utilities;

/* === reset === */
@layer reset {
  *, *::before, *::after { box-sizing: border-box; margin: 0; }
  body { line-height: 1.5; }
}

/* === base === */
@layer base {
  body { font-family: system-ui, sans-serif; color: #f8fafc; background: #0f172a; }
  h1, h2, h3 { line-height: 1.2; }
}

/* === components === */
@layer components {
  .tarjeta { padding: 16px; background: #1e293b; border-radius: 12px; }
  .tarjeta__boton { background: #34D399; padding: 10px 18px; border-radius: 8px; }
}

/* === utilities (SIEMPRE ganan) === */
@layer utilities {
  .mb-2   { margin-bottom: 8px; }
  .mb-4   { margin-bottom: 16px; }
  .text-center { text-align: center; }
  .sr-only {
    position: absolute; width: 1px; height: 1px;
    padding: 0; margin: -1px; overflow: hidden;
    clip: rect(0, 0, 0, 0); white-space: nowrap; border: 0;
  }
}

Reducir especificidad: :where() y preferir clases

La especificidad se acumula: #header .nav .item a pesa más que .link y es casi imposible de sobrescribir. Hay dos hábitos que ayudan:

CSS 
/* 1) usar :where() para reglas que no deben "ganar" */
:where(h1, h2, h3, h4, h5, h6) {
  font-weight: 600;
  line-height: 1.2;
}

/* 2) preferir CLASES sobre IDs */
/* MAL: #usuario .tarjeta .boton { ... } */
/* BIEN: .usuario__tarjeta__boton { ... } */

Un buen sistema CSS tiene especificidad plana: la mayoría de las reglas son clases simples (especificidad 0,1,0). Eso permite que las utilities, que están en la última capa, ganen siempre con su misma especificidad.

04PROYECTO · Refactor del sitio del bloque HTML

Este es el proyecto que cierra el bloque CSS. La idea es tomar el sitio que armaste al final del bloque HTML (M14) y refactorizarlo aplicando todas las técnicas de este módulo. El bloque de la derecha es el resumen ejecutivo — abrí el playground completo para empezar.

Checklist del refactor

Cinco pasos, en orden. Cada paso resuelve un problema distinto:

1) BEM: renombrá todas las clases siguiendo bloque__elemento--modificador
   .tarjeta          → .tarjeta
   .tarjeta h3       → .tarjeta__titulo
   .boton.activo     → .boton--activo

2) @layer: dividí el CSS en cuatro capas explícitas
   @layer reset, base, components, utilities;
   (comprobá en DevTools que las utilities ganan sobre los components)

3) container queries: pasá la galería o tarjetas a layout por contenedor
   .galeria { container-type: inline-size; }
   @container (min-width: 400px) { .tarjeta { grid-template-columns: 1fr 2fr; } }

4) imágenes responsivas: usá srcset y <picture> (introducido en M21)
   <img srcset="img-1x.jpg 1x, img-2x.jpg 2x" src="img-1x.jpg" alt="...">
   <picture>
     <source media="(max-width: 600px)" srcset="cuadrada.jpg">
     <source media="(min-width: 601px)" srcset="panoramica.jpg">
     <img src="panoramica.jpg" alt="...">
   </picture>

5) tema claro/oscuro: custom properties en :root + .tema-oscuro que las sobrescribe
   :root { --color-fondo: #f8fafc; --color-texto: #0f172a; }
   .tema-oscuro { --color-fondo: #0f172a; --color-texto: #f8fafc; }
   (sin tocar el resto del CSS — ese es el superpoder de las variables)

Cómo se ven las cinco técnicas juntas

Un fragmento pequeño que muestra BEM + nesting + @layer + variables en acción:

CSS 
@layer components {
  .galeria { container-type: inline-size; padding: 16px; }

  .tarjeta {
    background: var(--color-superficie, #1e293b);
    color: var(--color-texto, #f8fafc);
    border-radius: 12px;
    padding: 16px;

    &__titulo { font-size: 1.25rem; margin-bottom: 8px; }
    &__cuerpo { line-height: 1.6; margin-bottom: 16px; }
    &__boton {
      background: #34D399;
      color: #06120B;
      border: 0;
      padding: 10px 18px;
      border-radius: 8px;
      cursor: pointer;
      font-weight: 600;

      &:hover { transform: scale(1.05); }
      &--destacado { background: #fbbf24; }
    }

    @container (min-width: 400px) {
      display: grid;
      grid-template-columns: 1fr 2fr;
      gap: 16px;
    }
  }
}
