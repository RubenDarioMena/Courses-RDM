MÓDULO 25 · TRANSFORM

Transformaciones 2D y 3D

La propiedad transform mueve, rota, escala y deforma un elemento sin tocar el flujo de la página. Es la base de cualquier efecto visual: un card que se inclina, una imagen que hace zoom, un cubo que rota en 3D.

Sin instalar nada Pruébalo en el editor ~12 min de lectura
iLa idea en una imagen

Transformar es trasladar el sistema de coordenadas de un elemento, no cambiar su tamaño real. El elemento "se mueve" visualmente pero la caja lógica que ocupa sigue intacta. Eso es lo que hace que las animaciones con transform sean baratas: no recalculan el layout, solo le piden a la GPU que redibuje la capa.

2D
translate · rotate · scale · skew
Cuatro funciones que cubren casi todos los efectos planos: mover, girar, agrandar, inclinar.
3D
rotateX · rotateY · perspective
Mismo lenguaje pero con un eje Z. Necesitás perspective en el padre y transform-style: preserve-3d en el contenedor.
Origen
transform-origin: 50% 50%
El punto desde donde se aplica la transformación. Cambiarlo cambia todo el efecto: rotar desde una esquina es muy distinto a rotar desde el centro.
01Transformaciones 2D: las cuatro funciones base

Las funciones 2D se pueden combinar en una sola declaración. Se aplican de derecha a izquierda en la lista: la última se aplica primero al elemento.

CSS 
.caja {
  width: 80px;
  height: 80px;
  background: #34D399;
  border-radius: 12px;
  transform: translate(20px, -10px)
             rotate(15deg)
             scale(1.2)
             skewX(-5deg);
}

Las cuatro funciones 2D

Una por una. Todas aceptan longitudes, porcentajes o ángulos según corresponda:

CSS 
translate(20px, -10px)   /* mueve en X e Y                              */
rotate(45deg)           /* rota en el plano (sentido horario positivo) */
scale(1.2, 0.8)         /* agranda en X, encoge en Y (1 = sin cambio)  */
skewX(-10deg)           /* inclina el eje horizontal                   */

Combinación: encadenalas en una sola declaración separadas por espacio. El orden importa: rotate(45deg) translate(50px) y translate(50px) rotate(45deg) terminan en lugares distintos, porque la traslación se mide en el sistema ya rotado.

023D: rotar en el eje Z (y un poco de perspective)

Para entrar en 3D necesitás dos cosas: perspective en el contenedor padre (qué tan "lejos" está el observador) y, dentro de él, las funciones 3D como rotateX, rotateY o translateZ.

CSS 
.escena {
  perspective: 1000px;
  perspective-origin: 50% 50%;
}
.cubo {
  width: 120px;
  height: 120px;
  background: linear-gradient(145deg, #34D399, #10B981);
  border-radius: 14px;
  transform: rotateY(35deg) rotateX(10deg);
  transform-style: preserve-3d;
}

Funciones 3D y propiedades clave

La familia 3D es la misma idea que 2D pero con un eje Z. Si necesitás componer varios elementos en un mismo espacio 3D (un cubo con seis caras, una galería que rota), transform-style: preserve-3d es obligatorio en el padre:

CSS 
rotateX(20deg)          /* inclina hacia adelante/atrás       */
rotateY(-30deg)         /* gira como una puerta                */
rotateZ(45deg)          /* idéntico a rotate(45deg) en 2D      */
translate3d(0, 0, 50px) /* empuja al elemento hacia el observador */
transform-style: preserve-3d;  /* los hijos viven en el mismo espacio 3D */

Regla práctica: si ves que un rotateY se ve "plano" como un simple escalado, te falta perspective en algún ancestro. Sin perspectiva, el navegador aplana el 3D a 2D antes de pintarlo.

03transform-origin y will-change

Dos propiedades que parecen menores pero cambian completamente el resultado. transform-origin define el pivote de la transformación. will-change le avisa al navegador que prepare la capa en GPU porque vamos a animar esto.

transform-origin

Por defecto, el origen es el centro del elemento (50% 50%). Pero podés moverlo a una esquina, un borde o un punto exacto. Esto es lo que hace que un card "abra como una puerta" desde el lado izquierdo en vez de girar sobre sí mismo:

CSS 
transform-origin: 50% 50%;    /* centro (default) */
transform-origin: 0% 50%;     /* borde izquierdo    */
transform-origin: 100% 100%;  /* esquina inferior derecha */
transform-origin: 20px 80px;  /* píxeles exactos     */

will-change: el "modo GPU"

will-change no es una propiedad decorativa: le dice al navegador "subí esto a una capa compuesta". Usala con cuidado (solo en elementos que realmente se animan, y solo poco antes de la animación), porque usarla en demasiados elementos consume memoria.

CSS 
.card:hover .card-inner {
  transform: rotateY(180deg);
  will-change: transform;     /* pista al navegador */
}

.img-zoom:hover img {
  transform: scale(1.2);
  will-change: transform;
}

Regla de oro: poné will-change en el :hover o en el momento en que la animación empieza. Nunca en frío sobre elementos que "podrían" animarse.

04Tu primer momento: flip card + zoom

El bloque de la derecha es el único que se ejecuta inline y aplica los estilos al preview de abajo. Después abrí el playground completo para ver el flip card en HTML real con su CSS de 3D.

CSS 
.preview-wrap {
  display: flex;
  gap: 24px;
  align-items: center;
  justify-content: center;
  padding: 16px;
}

/* === flip card === */
#flip {
  width: 120px;
  height: 80px;
  position: relative;
  perspective: 800px;
}
#flip-inner {
  width: 100%;
  height: 100%;
  position: relative;
  transform-style: preserve-3d;
  transition: transform 0.6s;
  will-change: transform;
}
#flip: hover #flip-inner {
  transform: rotateY(180deg);
}
.face {
  position: absolute;
  inset: 0;
  display: flex;
  align-items: center;
  justify-content: center;
  border-radius: 10px;
  backface-visibility: hidden;
  font-weight: 600;
  color: #06120B;
}
#face-front { background: #10B981; }
#face-back  {
  background: #34D399;
  transform: rotateY(180deg);
}

/* === image zoom === */
#zoom {
  width: 120px;
  height: 80px;
  overflow: hidden;
  border-radius: 10px;
  background: #f1f5f9;
}
#zoom-inner {
  width: 100%;
  height: 100%;
  background: linear-gradient(135deg, #34D399, #0ea5e9);
  transition: transform 0.4s cubic-bezier(0.4, 0, 0.2, 1);
  will-change: transform;
}
#zoom: hover #zoom-inner {
  transform: scale(1.2);
}

3 detalles que hacen el truco

1

perspective en el PADRE

El contenedor padre lleva perspective: 800px. Sin esto, rotateY se aplana a 2D y se ve como un escalado horizontal.

2

backface-visibility: hidden

Oculta la cara trasera de cada lado. Sin esto, cuando el card rota se ven ambas caras superpuestas, no un flip limpio.

3

overflow: hidden para el zoom

El contenedor recorta la imagen que se agranda adentro. Sin overflow: hidden, la imagen se sale del card y se ve raro.
