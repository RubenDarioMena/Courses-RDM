Strings y template literals

Los strings son el pan de cada día en JavaScript. En este módulo vas a aprender a manipularlos como un profesional: cortarlos, buscarlos, limpiarlos, formatearlos con plantillas y entender por qué son inmutables (un detalle que cambia cómo piensas el código).

Métodos esenciales Plantillas reales ~12 min de lectura
1Inmutabilidad, .length e indexación

Un string nunca cambia

En JavaScript los strings son inmutables: una vez que creas uno, no puedes modificar sus caracteres. Los métodos como toUpperCase() o replace() devuelven un string nuevo, no mutan el original.

JavaScript · inmutabilidad
const saludo = "Hola, mundo";
console.log(saludo.length);                 // 11
console.log(saludo[0], saludo[10]);        // H o
const mayus = saludo.toUpperCase();
console.log(mayus);   // "HOLA, MUNDO"
console.log(saludo);  // "Hola, mundo" — intacto
2Los métodos que usarás a diario

Tu caja de herramientas

Estos métodos aparecen en el 90% del código real. Memoriza la forma en que devuelven resultados:

  • .slice(i, f?) — recorta un fragmento (fin exclusivo).
  • .indexOf(texto) — posición, o -1 si no existe.
  • .includes(texto) / .startsWith(texto) — booleanos.
  • .replace(a, b) — sustituye la primera; usa /a/g para todas.
  • .trim() — quita espacios al inicio y final. Oro puro con inputs.
  • .split(sep) — parte en array. split("") te da cada carácter.
  • .toUpperCase() / .toLowerCase() — mayúsculas/minúsculas.
JavaScript 
const f = "  Aprender JavaScript es urgente  ".trim();
console.log(f.slice(0,8));        // "Aprender"
console.log(f.indexOf("JavaScript")); // 9
console.log(f.includes("urgente"), f.startsWith("Aprender"));
console.log(f.replace("JavaScript","JS"));
console.log(f.split(" "));        // [palabras...]

3Template literals: la forma moderna

Backticks en lugar de comillas

Los template literals se escriben entre comillas invertidas (backticks) y permiten interpolar variables con ${} y escribir en varias líneas sin trucos.

JavaScript · template literals 
const nombre = "Ada";
const edad  = 36;
const tarjeta = `Hola, soy ${nombre}.
Tengo ${edad} años.
Lenguajes: ${edad > 30 ? "veterana" : "novata"}.
Símbolo: \u00A9  Tab: \t L\u00EDnea2`;
console.log(tarjeta);

Tagged templates (intro)

Una tagged template es una función que recibe el string y las partes interpoladas por separado. Se usa en librerías como styled-components o lit-html para transformar el resultado final antes de pintarlo.

La sintaxis es etiqueta`texto ${valor}`: el string se parte en fragmentos y los ${} llegan como argumentos extra. Profundizaremos en M43.

4Tu primer momento: plantilla de email

Junta todo lo aprendido en una plantilla de email real. Pulsa Ejecutar y observa cómo se construye el mensaje a partir de variables.

JavaScript · plantilla-email.js 
const para = "  María López  ".trim();
const asunto = "Recordatorio URGENTE: cita mañana";
const fecha = new Date().toLocaleDateString("es-ES");
const cuerpo = `Hola ${para},

Le recuerdo su cita del ${fecha} a las 10:00.

Por favor, confirme su asistencia.

Un saludo,
El equipo`;

const limpio    = cuerpo.replace("Hola", "Estimada");
const esUrgente = asunto.includes("URGENTE");
console.log("Para:", para, "| Asunto:", asunto);
console.log("Longitud:", limpio.length, "| Líneas:", limpio.split("\n").length);
console.log("¿Urgente?", esUrgente);
console.log("---");
console.log(limpio);
