Objetos y closures

Los objetos son el corazón de JS: agrupan datos y comportamiento. Y los closures — funciones que recuerdan su entorno — son la idea más poderosa del lenguaje. Hoy combinas ambas para escribir código de verdad.

Literales + this Closures ~18 min de lectura
1Objetos: literales, acceso, this

Crear y acceder

Un objeto literal es un diccionario de pares clave-valor: { nombre: "Ana", edad: 30 }. Se accede con punto (obj.nombre) o con corchetes (obj["edad"]) — los corchetes permiten claves dinámicas o con espacios. Los métodos abreviados ({ saludar() {} }) son azúcar sintáctico para { saludar: function() {} }.

Acceso

Punto o corchetes. Corchetes cuando la clave es variable o tiene espacios.

obj.nombre
obj["nombre"]
obj[clave]

Prop. computadas

Claves dinámicas entre [ ] en la definición del objeto.

{ [campo]: valor }

Métodos y this

Dentro de un método, this apunta al objeto que llama.

{ resumen() { return this.titulo; } }
2Tu primer momento: libro + contador + API

Pulsa Ejecutar. Tres demos juntos: un objeto libro con método que usa this, un contador con closure que mantiene estado privado, y la desestructuración anidada de una respuesta de API simulada. Cierra con un ejemplo de structuredClone para copia profunda.

JavaScript · objetos.js 
// 1. Objeto libro con this y método abreviado
const libro = {
  titulo: "El Quijote",
  autor: "Cervantes",
  año: 1605,
  resumen() { return `"${this.titulo}" de ${this.autor}`; }
};
console.log(libro.resumen());

// 2. Contador con closure (estado privado)
function crearContador() {
  let cuenta = 0;
  return {
    incrementar() { cuenta++; return cuenta; },
    decrementar() { cuenta--; return cuenta; },
    valor() { return cuenta; }
  };
}
const c = crearContador();
c.incrementar(); c.incrementar(); c.incrementar();
console.log("contador:", c.valor());  // 3 — no se puede tocar "cuenta" desde fuera

// 3. Desestructuración anidada (respuesta de API)
const respuesta = { data: { usuario: { nombre: "Ana", rol: "admin" } } };
const { data: { usuario: { nombre, rol } } } = respuesta;
console.log(`API → ${nombre} (${rol})`);

// 4. Clonación: spread vs structuredClone
const original = { nombre: "Ana", dir: { ciudad: "Madrid" } };
const copiaSuperficial = { ...original };
const copiaProfunda = structuredClone(original);
copiaProfunda.dir.ciudad = "Lima";
console.log("orig sigue Madrid:", original.dir.ciudad);

3Closures: funciones con memoria

Qué es un closure

Un closure es una función que recuerda el ámbito donde nació, incluso después de que ese ámbito haya terminado. crearContador devuelve funciones que "ven" cuenta y la mantienen viva entre llamadas. Es la base de variables privadas, factories, partial application y patrones como módulos.

Referencia vs copia

Los objetos se asignan por referencia: const b = a no copia, hace b apunte al mismo objeto. Para una copia superficial usa {...obj} o Object.assign({}, obj). Para una copia profunda (con sub-objetos) usa structuredClone(obj) — disponible en navegadores modernos y Node 17+.

this, bind, call, apply

Dentro de un método, this apunta al objeto que invoca. Si extraes el método (const f = obj.saludar) y lo llamas suelto, this se pierde. obj.saludar.bind(obj) crea una versión "ligada" donde this siempre será obj. call y apply invocan inmediatamente con un this concreto.
