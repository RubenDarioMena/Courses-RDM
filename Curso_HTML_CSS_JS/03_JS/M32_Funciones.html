MÓDULO 32 · FUNCIONES

Funciones: declaración a arrow

Una función es un bloque de código con nombre que puedes llamar cuando quieras. Es el ladrillo con el que se construyen programas que crecen sin volverse caóticos. Hoy ves declaración, expresión, arrow functions y callbacks.

3 sintaxis Rest + default ~14 min de lectura
1Las tres formas de crear funciones

Declaración, expresión y arrow

Las tres hacen lo mismo, pero se comportan distinto. Las declaraciones se "eleven" (hoisting): puedes llamarlas antes de escribirlas. Las expresiones y arrow functions son valores: se asignan a variables, se pasan como argumento, se devuelven.

Declaración

Forma clásica. Se eleva completa: callable desde cualquier punto del scope.

function sumar(a, b){ return a + b; }

Expresión

Una función asignada a variable. No se eleva; solo callable tras la asignación.

const sumar = function(a,b){...};

Arrow

Concisa, sintaxis moderna. Sin this propio. Ideal para callbacks.

const sumar = (a, b) => a + b;
2Tu primer momento: callbacks en acción

Pulsa Ejecutar. aplicar(arr, fn) es una función de orden superior: recibe otra función (duplicar, triplicar) y la aplica a cada elemento. Después, una función con parámetro por defecto y otra con ...rest que suma lo que le pases.

JavaScript · funciones.js 
// HOF: función que recibe otra función
function aplicar(arr, fn) {
  const out = [];
  for (const x of arr) out.push(fn(x));
  return out;
}

// Arrow functions con retorno implícito
const duplicar = x => x * 2;
const triplicar = x => x * 3;

console.log("duplicar [1,2,3]:", aplicar([1,2,3], duplicar));
console.log("triplicar [1,2,3]:", aplicar([1,2,3], triplicar));

// Parámetro por defecto
function saludar(nombre = "invitado") {
  return "Hola, " + nombre;
}
console.log(saludar());        // "Hola, invitado"
console.log(saludar("Ana")); // "Hola, Ana"

// Rest: agrupa el resto de argumentos en un array
function sumarTodo(...nums) {
  return nums.reduce((a, b) => a + b, 0);
}
console.log("sumarTodo(1..5):", sumarTodo(1,2,3,4,5));

3Parámetros y funciones de orden superior

Parámetros por defecto y rest

Por defecto: function f(x = 10) — si no pasas x, vale 10. Útil para evitar undefined. Rest: ...args agrupa los argumentos restantes en un array real (no un arguments exótico). Solo puede haber un rest y debe ir al final.

Funciones de orden superior y callbacks

Una HOF (Higher-Order Function) recibe o devuelve otra función. aplicar(arr, fn) es HOF: recibe fn como callback. Los arrays de JS vienen repletos de HOFs: map, filter, reduce — todas reciben callbacks. Entenderlas ahora te prepara para el módulo de arrays.
