DOM y eventos

Hasta ahora tu JS corría en la consola. Aquí aprende a tocar la página: leer lo que el usuario escribió, cambiar texto, crear elementos, reaccionar a clics. Es el módulo donde la página cobra vida.

querySelector addEventListener ~25 min de lectura
1 Seleccionar elementos del DOM

El DOM (Document Object Model) es la representación en árbol de tu HTML. Cada etiqueta es un nodo al que puedes preguntar con JS. Hay cuatro formas principales de "agarrarlos":

getElementById
document.getElementById('app')
El más rápido. Devuelve un elemento (o null). Solo sirve para IDs.
querySelector
document.querySelector('.btn')
Acepta cualquier selector CSS. Devuelve el primero que coincida o null.
querySelectorAll
document.querySelectorAll('li')
Devuelve todos como NodeList (no es un array, pero se puede recorrer con forEach).
getElementsByTagName
document.getElementsByTagName('p')
Histórico, devuelve HTMLCollection viva (se actualiza sola). Menos común hoy.
2 Manipular: cambiar lo que hay en pantalla

Una vez que tienes el nodo, puedes cambiar casi todo. Regla de oro: usa textContent para texto seguro, innerHTML solo cuando necesites HTML y confíes en la fuente.

JavaScript · manipulación del DOM 
// Texto plano (SEGURO, recomendado)
titleEl.textContent = 'Hola';

// HTML (cuidado: si viene del usuario, sanitizar)
contentEl.innerHTML = '<strong>Importante</strong>';

// Clases CSS
btnEl.classList.add('active');
btnEl.classList.toggle('hidden');

// Atributos
linkEl.setAttribute('href', '/nuevo');

// Estilos inline (usar con moderación)
boxEl.style.setProperty('background', '#A78BFA');

Seguridad: nunca hagas innerHTML = inputUsuario sin sanitizar. Es la puerta de entrada del XSS. Para texto de usuario, usa siempre textContent.

3 Crear e insertar elementos

Para añadir nodos nuevos al árbol: createElement los crea, appendChild los pega al final. insertAdjacentHTML es el atajo para meter HTML en una posición concreta.

JavaScript · crear nodos 
// Crear un <li> con texto y agregarlo a una lista
const li = document.createElement('li');
li.textContent = 'Nuevo item';
listEl.appendChild(li);

// Atajo: insertar HTML en una posición
listEl.insertAdjacentHTML('beforeend', '<li>Otro</li>');

// Las 4 posiciones posibles: 'beforebegin' | 'afterbegin' | 'beforeend' | 'afterend'
4 Eventos: reaccionar al usuario

addEventListener('click', función) es el patrón canónico. La función recibe un objeto event con info del clic. Los eventos más usados: click, input, submit, keydown, DOMContentLoaded.

JavaScript · addEventListener 
btn.addEventListener('click', function(e){
  console.log('Clic en:', e.target);
});

// input: se dispara en CADA pulsación (con debounce si hace falta)
searchInput.addEventListener('input', e => console.log(e.target.value));

// submit: ¡siempre preventDefault() o recargas la página!
form.addEventListener('submit', e => {
  e.preventDefault();
  // procesar datos...
});

// DOMContentLoaded: el HTML ya está listo, podemos tocar el DOM
document.addEventListener('DOMContentLoaded', () => {
  init();
});

Delegación de eventos

En lugar de poner un listener en cada botón, pon uno solo en el contenedor padre y usa event.target para saber qué hijo fue clicado. Funciona también con elementos creados dinámicamente.

JavaScript · delegación 
// MAL: un listener por botón. Si luego agregas más, no responden.
document.querySelectorAll('.btn').forEach(b =>
  b.addEventListener('click', handleClick)
);

// BIEN: un listener en el contenedor, detecta cualquier hijo .btn
container.addEventListener('click', e => {
  if (e.target.matches('.btn')) handleClick(e);
});
