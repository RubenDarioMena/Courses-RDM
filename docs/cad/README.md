# Documentación de Taller CAD

**Estado: provisional. Pendiente de revisar y pulir con el usuario.**

Estos documentos separan el estado comprobado de las propuestas para convertir Taller CAD en un proyecto propio. Las propuestas no son compromisos de alcance, calendario ni arquitectura futura.

| Documento | Para qué sirve | Estado |
| --- | --- | --- |
| [Progreso de la entrega](PROGRESO.md) | Trabajo terminado, pruebas, límites y continuidad. | Informe de cierre; revisable. |
| [Plan de producto y desarrollo](PLAN_PROVISIONAL.md) | Base para conversar sobre objetivos, prioridades y próximas etapas. | Provisional; pendiente de decisiones. |
| [Separación a un proyecto propio](SEPARACION_PROVISIONAL.md) | Inventario, pasos y decisiones para extraer CAD del sitio de cursos. | Propuesta pendiente; no se ha realizado la separación. |
| [Arquitectura técnica actual](../CAD_WEB.md) | Implementación, formato de documento, dependencias, licencias y reproducción. | Describe el código existente; consultar sus límites. |

La documentación de Arena y Codemageddon corresponde a otro producto. No debe usarse como requisito del editor CAD. La portada y los cursos existentes mantienen su alcance y funcionamiento.

Al terminar nuevas entregas, actualizar el informe con hechos comprobados y enlaces a sus pruebas. Las propuestas deben seguir identificadas como pendientes hasta que el usuario las acepte.
