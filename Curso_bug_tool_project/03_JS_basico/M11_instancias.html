Instancias: múltiples bugs a la vez

La herramienta permite tener varios bugs abiertos al mismo tiempo, como pestañas del navegador. Cada bug es una 'instancia' con sus propios valores.

⚡ JS~10 minIntermedio
1makeInstance: crear un bug vacío
JavaScript
function makeInstance(formId) {
  const form = getForm(formId);
  const values = {};
  allFields(form).forEach(({ field }) => {
    if (field.type === "mirror") return;
    if (field.type === "keywords") values[field.id] = [];
    else values[field.id] = resolveRef(field.default || "");
  });
  return { id: newId(), formId, values, dirty: false, errors: {} };
}

Cada instancia es un objeto con values (los valores que el tester escribe), dirty (si tiene changes sin guardar) y errors. Los valores iniciales se rellenan con resolveRef(field.default): si el campo tiene "@default_tz", resolveRef busca default_tz en las reglas y pone "CST".

2ensureInstanceFields y getActiveInstance
JavaScript
function ensureInstanceFields(inst) {
  allFields(getForm(inst.formId)).forEach(({ field }) => {
    if (inst.values[field.id] === undefined)
      inst.values[field.id] = resolveRef(field.default || "");
  });
}
function getActiveInstance() {
  return state.instances.find(i => i.id === state.activeInstanceId);
}

ensureInstanceFields completa campos nuevos que el schema añadió después de que la instancia se creó — sin pisar los que ya tienen valor. getActiveInstance busca en el array la instancia apuntada por activeInstanceId. El punto naranja "dirty" se activa con markInstanceDirty, que refresca las sub-pestañas.

3El array state.instances: como pestañas del navegador

Cada instancia es independiente: cambiar valores en una no afecta a las demás. Es como tener varias pestañas del navegador abiertas, cada una con un bug distinto. El array state.instances las guarda a todas, y state.activeInstanceId apunta a cuál está visible.

El objeto instancia completo

Cada instancia tiene: id (único), formId (a qué formulario pertenece), values (lo que el tester escribió), errors (errores de validación), dirty (¿tiene cambios sin guardar?), ticketKey y media (para los nombres de archivos).

4Tu primer momento: crear instancias

Pulsa Ejecutar para ver cómo se crean 3 instancias y se marcan como dirty.

JavaScript — simular makeInstance
// Crear 3 instancias como hace la herramienta:
var instances = [];
for (var i = 0; i < 3; i++) {
  var inst = {
    id: "bug_" + (i + 1),
    formId: "bug",
    values: { team: "QA", map: "Highrise" },
    dirty: false,
    errors: {}
  };
  instances.push(inst);
}
// Marcar como dirty (cambios sin guardar):
instances[1].dirty = true;
instances.forEach(function(i) {
  console.log(i.id + " | dirty: " + i.dirty + " | map: " + i.values.map);
});

1

var state = { instances: [], activeInstanceId: null };

2

Crea 3 instancias

3

Marca la segunda como dirty

Cambia instances[1].dirty = true y verifica que las otras siguen false.

4

Busca la activa
