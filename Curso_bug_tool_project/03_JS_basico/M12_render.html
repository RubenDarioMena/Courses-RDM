Render dinámico: pintar el formulario desde el schema

El formulario no está escrito a mano en el HTML. Se pinta desde JavaScript leyendo el JSON del schema: cada campo se genera dinámicamente. Es la idea central de una app data-driven.

⚡ JS~10 minIntermedio
1renderTopTabs: pestañas desde el schema
JavaScript
function renderTopTabs() {
  $("formTabs").innerHTML = getForms().map(f =>
    `<div class="top-tab" data-form="${f.id}">${escapeHtml(f.label)}</div>`
  ).join("");
}

No hay <div>Bug</div> escrito a mano. Las pestañas se generan desde config.schema.forms. Cada formulario del JSON se convierte en una pestaña. Si la config define 5 formularios, aparecen 5 pestañas.

2fieldHtml: HTML por tipo de campo
JavaScript
function fieldHtml(field, inst, fx) {
  if (field.type === "textarea")
    return `<textarea data-bind="${field.id}">...`;
  if (field.type === "autocomplete")
    return `<input data-bind="${field.id}" data-ac="${field.id}">...`;
  return `<input type="text" data-bind="${field.id}">`;
}

El atributo data-bind

Cada input tiene data-bind="fieldId". En wireFormEvents, se registran listeners de input, blur y change. Cuando el tester escribe, el JS pone inst.values[fieldId] = el.value y revalida.

3renderForm: pintar secciones y campos

renderForm es la función que une todo: lee el schema del formulario activo, recorre sus secciones y pinta el HTML en #formPanel. Después de pintar, llama a wireFormEvents para conectar los inputs.

JavaScript — renderForm (simplificado)
function renderForm() {
  const form = getForm(state.topTab);
  const inst = getActiveInstance();
  let html = "";
  form.sections.forEach(sec => { html += sectionHtml(sec, inst, fx); });
  $("formPanel").innerHTML = html;
  wireFormEvents(inst, form);
}

El patrón: render · wire · validate

La herramienta sigue 3 pasos cada vez que algo cambia: render (pinta HTML), wire (conecta eventos), validate (verifica valores). Si solo cambia un valor, no re-render — basta con revalidate + reflectErrors.

4Tu primer momento: renderizar desde JSON

Pulsa Ejecutar para ver cómo se genera HTML desde un schema de 3 campos.

JavaScript
var fields = [
  { id:"team", label:"Team", type:"text", required:true },
  { id:"map", label:"Mapa", type:"text" }
];
var html = "";
fields.forEach(function(f){
  html += '<div class="field"><label>'+f.label;
  if(f.required) html += ' *</label>';
  else html += '</label>';
  html += '<input type="text"></div>';
});
console.log(html);
