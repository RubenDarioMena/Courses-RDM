Widget autocomplete: dropdown con texto libre

El autocomplete es el widget más complejo de la herramienta. Permite escribir texto libre, muestra opciones filtradas, deja agregar nuevas opciones a la lista, borrar existentes, navegar con teclado y abre hacia arriba o abajo según el espacio disponible. En este módulo lo desmontamos pieza por pieza.

⚡ JS Avanzado ~12 min de lectura Nivel: intermedio
1La idea en una imagen

Imagina el autocomplete como un buzón de correo: tú escribes una dirección y el cartero te muestra las que coinciden. Si no encuentras la que buscas, puedes añadir una nueva. Y si una dirección ya no sirve, la borras. Todo eso sin abrir la pestaña Data.

2wireAutocomplete: el widget completo

La función que conecta el input con el dropdown

La herramienta no usa el elemento nativo <datalist>. Construye su propio dropdown desde cero porque necesita tres cosas que <datalist> no ofrece: botón de borrar opción (✕), fila "+ Agregar" para sumar texto libre a la lista, y apertura hacia arriba cuando no cabe abajo.

JavaScript — wireAutocomplete (simplificado)
function wireAutocomplete(input, inst, form, field) {
  const wrap = input.closest(".autocomplete");
  const list = wrap.querySelector(".autocomplete-list");
  let activeIdx = -1;  // índice para navegación por teclado

  const renderList = (showAll) => {
    const all = optionsForField(field, inst); // lee la lista
    const q = input.value.trim().toLowerCase();
    let items = all;
    if (!showAll && q)
      items = all.filter(v => v.toLowerCase().includes(q));
    // ... pinta los items con  para resaltar coincidencias
  };

  input.addEventListener("focus", () => renderList(false));
  input.addEventListener("input", () => renderList(false));
  input.addEventListener("keydown", handleKeys);
}

El flujo completo

1

Focus → renderList(false)

Al enfocar el input, se pinta el dropdown. Si hay texto escrito, filtra; si no, muestra todas las opciones.

2

Input → renderList(false)

Cada tecla que escribes re-filtra la lista en tiempo real. El filtrado es case-insensitive con toLowerCase() + includes().

3

Click en item → rellena input

Al hacer clic en una opción, el input se rellena con el valor elegido y el dropdown se cierra.

4

Blur → cierra (con delay de 150ms)

El delay permite que el clic en un item del dropdown se registre antes de que se cierre.

3Filtrado y resaltado con <mark>

Cómo se resaltan las coincidencias

Cuando escribes "ofi", el dropdown no filtra solo — también pinta amarillo (con <mark>) la parte que coincide dentro de cada opción. Así el usuario ve por qué "Office A" coincide con "ofi".

JavaScript — resaltado
// Escapar el texto de búsqueda para usarlo en regex de forma segura
const re = q ? new RegExp("(" + q
  .replace(/[.*+?^${}()|[\]\\]/g, "\\$&") + ")", "ig") : null;

// Reemplazar el texto escapado por la versión con 
const marked = re
  ? escapeHtml(v).replace(re, "<mark>$1</mark>")
  : escapeHtml(v);

El truco: primero se escapa el HTML del valor (para evitar inyección), y después se aplica el <mark> con replace sobre el texto ya escapado. El regex construido con "\\$&" evita que caracteres especiales como . o $ del texto de búsqueda rompan el patrón.

4Navegación por teclado

ArrowDown, ArrowUp, Enter, Escape

El widget soporta navegación completa por teclado. Una variable activeIdx rastrea qué item está seleccionado. Las flechas mueven el índice, Enter lo confirma y Escape cierra sin seleccionar.

JavaScript — navegación por teclado
input.addEventListener("keydown", (e) => {
  const items = list.querySelectorAll(".autocomplete-item");
  if (e.key === "ArrowDown") {
    e.preventDefault();
    activeIdx = Math.min(items.length - 1, activeIdx + 1);
  } else if (e.key === "ArrowUp") {
    e.preventDefault();
    activeIdx = Math.max(0, activeIdx - 1);
  } else if (e.key === "Enter" && activeIdx >= 0) {
    e.preventDefault();
    input.value = items[activeIdx].dataset.v;  // confirma
    wrap.classList.remove("open");
    return;
  } else if (e.key === "Escape") {
    wrap.classList.remove("open");
    return;
  }
  // Marcar el item activo y hacer scroll dentro del dropdown
  items.forEach((it, i) => it.classList.toggle("active", i === activeIdx));
});

El scroll es inteligente: solo mueve el scroll del dropdown, no el de la página. Si el item activo queda fuera del viewport del dropdown, se desplaza con scrollTop para mantenerlo visible.

5"+ Agregar" y "✕ Borrar" opciones

Texto libre: agregar a la lista sin abrir la pestaña Data

Si escribes un valor que no existe en la lista, el dropdown muestra una fila "+ Agregar «texto» a la lista" al final. Al hacer clic, se añade el valor a config.data.lists y el input se rellena. El usuario nunca tiene que abrir la pestaña Data para eso.

✕ Borrar: confirmación antes de eliminar

Cada opción del dropdown tiene una ✕ a la derecha. Al hacer clic se abre un modal de confirmación. Si el usuario acepta, se borra el valor de config.data.lists y la lista se re-renderiza. También busca y elimina el valor de cualquier lista hija que lo contenga.

6positionAutocomplete: abrir arriba o abajo

Medir el espacio con getBoundingClientRect

Normalmente el dropdown abre hacia abajo. Pero si el campo está cerca del borde inferior del viewport, no cabe. La función positionAutocomplete mide con getBoundingClientRect() y, si no hay espacio, añade la clase .drop-up para que abra hacia arriba.

JavaScript — positionAutocomplete
function positionAutocomplete(wrap, list) {
  const r = wrap.getBoundingClientRect();
  const spaceBelow = window.innerHeight - r.bottom;
  const listHeight = list.offsetHeight;
  if (spaceBelow < listHeight && r.top > listHeight) {
    wrap.classList.add("drop-up");  // abre hacia arriba
  } else {
    wrap.classList.remove("drop-up");
  }
}
